## API 可以直接使用哪些能力

API 的访问方式是调用预先定义的工具，由本地工具实现返回许可内容；远程模型没有仓库挂载或 SSH/shell。

| 对象或动作 | 实际权限 |
|---|---|
| 冻结接口、公共训练配方、许可的 DP 源码 | 可用 list_files/read_file 读取，不能修改 |
| 当前 task×N 的证据 | 可读取当前 D_N 的轨迹、统计、任务材料和最多 16 张真实示范帧 |
| 其他 task×N 会话、B1 源码、历史设计与分数、隐藏测试文件 | 不在设计工具读取白名单内 |
| 初始候选 | 初始阶段仅能编辑自己的 A1/A2/A3；API 决定具体归纳偏置、配置和代码 |
| 接口检查 | 可调用固定 run_checks；每候选最多 3 次，不进行 optimizer update 或任务表现评估 |
| 提交候选 | API 显式提交当前版本哈希；必须已通过该精确版本的检查，提交后不可改 |
| 开发反馈与修订 | A1/A2/A3 全部提交并完成开发后才开放反馈；随后只允许新建 A4 |
| 最终选择 | API 提交 q4，固定规则重新验证；本次没有 api_selection_noncompliant |
| 训练、开发评估、隐藏测试、GPU 调度 | 外层 runner 执行，不是 API 的工具能力 |
| API key、shell、网络和任意执行 | 设计工具不提供；候选 worker 采用凭据环境白名单、Landlock 和 seccomp |

已核对的 worker request 包括 145 次 train、288 次 policy、97 次 validate。正式候选的读取授权仅包含自己的候选或 checkpoint、精确 D_N 和明确公共运行文件；环境中没有 TOKEN/SECRET/KEY 变量，均有 enforcement 回执。部分原始支持示范位于历史归档目录，这是协议保留的共享原始数据，不是历史候选代码或输出复用。

阶段时间证据（UTC）：最后一次 API 响应约为 2026-09-13 06:03:31，全局冻结文件 mtime 为 06:03:47，首个隐藏测试 policy worker 为 06:04:04。全部初始 A 候选的训练都晚于同实例三候选提交。

## 证据边界

1. 本次验证的是本机 Responses 代理收据与仓库工件的一致性。冻结地址为 http://127.0.0.1:8080；未取得上游模型服务商独立签名或外部账单凭证。因此不能把本机 provenance 字段或 response ID 当作独立的上游身份认证。
2. 开发 Codex/仓库所有者仍有宿主机写权限。候选对公共文件和其他数据的隔离是强制执行的，但提交的不可变性是工具拒绝和哈希核验保证的，不是防宿主机管理员篡改的外部存证。
3. global_freeze.json 本身没有显式创建时间字段；本次时间顺序由文件 mtime、API 日志、worker 回执及测试引用的冻结哈希交叉佐证，不能视为独立签名时间戳。
4. reports/live_execution_audit.json 是 2026-09-12 早期运行快照，仅记录当时进度；当前状态应参考完整工件验证和本次核查。
