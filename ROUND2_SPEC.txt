0. 研究目的：建立“任务变化—先验—策略收益”的对应关系

Round 1 已完成 drawer/door × raw/relative 四次训练。每任务 20 条示范，四个模型的 IID 与位置 OOD 成功率均为 100%；Drawer OOD 平均完成步数为 135.70→93.55。它说明原测试已经饱和，不能据此判断一般先验的价值。

本轮研究：在同一批有限示范、相同可用状态信息和训练预算下，把物体朝向相关的坐标变换同时用于观测和动作，是否扩大策略能成功执行的空间变化范围？

主线是增强任务的几何变化，并实现与其对应的先验。继续使用 20 条示范，不优先改成 5 条；不削弱 baseline 的网络、训练预算或传感信息。

本轮仅完成几何实验，不加入 ABC 组合、VLM Agent、自动搜索、层级策略、阶段预测器、额外约束 loss 或关节轴硬投影。成功率、几何泛化和失败位置分别报告；无需预设结果一定为正。

2. 自定义物理任务：真正旋转柜体

基于固定版本 drawer-open-v3 和 door-open-v3 添加项目内的独立环境类/适配层。明确命名为自定义 MetaWorld 扩展，不能称为未经修改的标准 benchmark。

2.1 固定的物理接口

仍使用现有 Sawyer、原生 4 维 Cartesian 增量加夹爪接口、原生控制频率和物理时间步。

保持机器人基座、桌面和重力不动，绕柜体基座的世界竖直轴施加 yaw；不要把机器人和整个世界一起转动，也不要只旋转图片或观测数值。

柜体根节点、碰撞几何、内部关节轴和把手必须保持正确父子关系。确认实际旋转发生在正确的固定父节点，而非误改正在转动的门叶。

先记录 yaw=0 的原始根节点位姿；所有 reset 从原始值重新构造，不能累计旋转。变换合成顺序依据 MuJoCo 约定验证。

本轮 yaw 在整个 episode 内固定。不要引入运行中变化的参考系或控制器。

原生接口固定了末端朝向，不能保证任意柜体 yaw 都可操作；第 3 节会先确定可行范围。不要在本轮升级成 6D action。

2.2 正确的观测和把手几何

审查安装版本中的 _get_pos_objects、_get_quat_objects、目标构造和 reset 历史缓存。

原任务可能通过“某 body 位置 + 写死的世界方向 offset”构造交互点。旋转后必须把该 offset 当作对应物体局部向量旋转，或使用经核验的真实 site/geom。

特别检查 Drawer 的把手 offset；不能只转柜体却让观测中的把手留在错误位置。

不同任务四元数可能分别使用 wxyz/xyzw。统一项目内真实姿态字段的约定，并记录转换，不能猜测。

先完成模型位姿、关节状态、目标和 forward，再构造当前观测及 native 历史；防止 reset 历史缓存还对应旋转前场景。

保存请求 yaw 和实际模型 yaw、实际把手/基座位姿。验证几何变换，不仅检查 reset 参数。

2.3 固定物理目标与成功定义

原生 Door 的世界坐标分量阈值未必随 yaw 有效。本轮统一采用明确的关节打开进度，而不是继续调用不适用的原生 success。

检查并固定每任务的关闭参考 q_closed，以及由模型关节范围和原生开门方向确定的打开端点 q_open。使用：

progress = (q - q_closed) / (q_open - q_closed)

q_open 的符号必须由机构验证；正负开合均可。若该关节未配置有限范围，先从任务模型/原生目标确定有限物理端点并记录依据，不能凭模型结果设阈值。

默认把目标设在 progress=0.80；成功定义为 progress>=0.75，连续 3 个 env.step 成立。超出关节范围的异常不能当作成功。

所有 yaw、位置和两种策略使用完全相同的 q_closed/q_open/目标/成功阈值。

在目标关节配置通过 FK 计算真实 goal handle pose，再完整恢复当前物理状态；或者使用验证过的解析几何。不得用未来真实 rollout 位置构造目标。

success、episode 终止和报告都使用本轮定义。最大 500 env.step，若现有 TimeLimit 更短则统一记录并使用；原生“已成功”的包装器不能提前截断本轮任务。

BC 不使用奖励，可用进度差/进度作为诊断 reward；不要把未更新的 native reward 当作跨 yaw 的可靠比较。

零动作初始状态必须未成功，柜体不能自发打开。验证关闭、中间、目标附近的状态及正负 yaw。

这是新任务协议，不能把 Round 1 与 Round 2 的成功率变化直接当作算法差距。

允许在正式训练前，依据物理模型错误或专家无法完成的具体证据修正上述环境实现。任何成功定义调整都必须在校准阶段记录理由、数值和所有受影响数据；正式训练后冻结。

5. 两个策略看到相同信息

采用 state input。复用已核验的 native 39 维结构（18 当前+18 历史+3 goal），但必须以实际源码/schema 为准，不硬编码错误字段。追加相同的柜体 yaw 元数据 (sin(theta), cos(theta)) 到两种表示。

这里 theta 是本轮相对于原始柜体设置额外施加的世界竖直轴 yaw，R=Rz(theta)；theta=0 时 R=I。验证真实根节点变换与该定义一致。

world 和 frame 获得相同的当前/历史机器人状态、把手状态、目标、姿态和 yaw 信息。

yaw 是本轮人工提供的正确元数据，用于隔离先验干预本身；不是 Agent 推断，也不是视觉估计。

不把 q/progress、success、接触阶段、剩余步数、未来观测或专家内部状态新增为 policy input；若某项本来就在共享原始观测中，记录现状。

需要额外几何字段时，先确认必要性并同等提供给两方法；保留信息一致性与同维度。

5.1 world 表示

使用修正后的世界坐标观测，以及上述相同的 yaw 元数据；输出世界坐标动作。

5.2 frame 表示

R 在 episode 内固定。对每个真实位置块，令 h 为该观测时刻真实 handle 位置：

p_hand_F = R.T @ (p_hand_W - h_W)
h_output = h_W
p_goal_F = R.T @ (p_goal_W - h_W)

保留 h 的世界坐标，因此可逆；不删除其他世界状态以制造精确不变性。

native 历史块用自己的 h；goal 尾部用当前块 h。

DP 外部两步历史中的每个观测也按其自身时间处理。

真实物体姿态矩阵变换为 Q_F=R.T@Q_W；统一四元数约定和符号连续性。真实方向/速度若存在用 R.T 旋转，不能当位置减 h。

不存在的第二物体零占位保持零；夹爪标量保持不变。

保留相同 yaw 元数据，以支持逆变换。

这里只使用固定柜体参考方向，不使用不断旋转的门叶参考系，不加入“沿门切向”的手工控制器。

5.3 输入归一化

位置与普通连续标量使用各表示自身 train20 的 mean/std，规则相同，std 下限 1e-3。

sin/cos yaw 和真实单位四元数保留原有有界数值，不做 train-variance 标准化；两方法相同。狭窄 yaw 训练范围下 cos 的方差很小，不能人为制造巨大的 OOD 输入。

常量零占位保持零，记录字段分类与统计来源。

不裁剪 OOD 输入，不使用 dev/test 统计。

6. 动作的坐标变换与 diffusion 边界

先核对原生 xyz 动作如何转成物理位移。若三个轴使用相同缩放 s，则：

a_frame_xyz = R.T @ a_world_xyz
a_frame_gripper = a_world_gripper
decoded_world_xyz = R @ predicted_frame_xyz

动作是增量向量，只旋转，不减 handle、不减基座位置。整个 16 步 chunk 使用当前已经知道的固定 R；不使用任何未来 handle、关节角或观测。

训练保存世界坐标下已实际执行的动作。world loader 直接使用；frame loader 旋转这些相同标签。不要重新规划一套局部轨迹当作不同监督。

若源码的 xyz 缩放是各轴不同的矩阵 S，应在物理位移 d=Sa 上旋转，并对两方法使用同一个预定标量 s0=max(diag(S))：world target=d/s0，frame target=R.T@d/s0；执行时 world native action=S^-1(s0*target_world)。不能直接旋转不等比例的归一化控制量。若原生缩放各轴相同，使用上面的简单式即可。

必须修正 Round 1 的中间动作裁剪：

世界坐标 [-1,1]^3 内的向量，旋转后局部坐标某个分量可能超过 1。因此两模型都设置：

clip_sample: false
thresholding: false

不对局部训练标签或中间 predicted clean actions 按 [-1,1] 裁剪。

不按每轴示范 min/max 或方差另做 action normalization。

推理结束后，先把最终结果解码成世界坐标原生动作，再按同一 native action_space 裁剪，然后 env.step；夹爪同样按原生边界裁剪。

world 策略也只使用这套最终动作边界处理。

报告 world/frame 最终裁剪比例；不要把裁剪发生隐藏起来。

两方法都改变这项设置，是为了处理旋转后正确的动作支持范围；这不是与旧 Round 1 的单因素比较。不要另加 L2 球动作限制、控制器或执行救援。

train_seed: 0
checkpoint_updates: [5000,10000,20000]

损失为有效 action entries 上的 epsilon MSE，无其他 loss。保持已有 float32/TF32/确定性/compile 约定；若兼容性要求统一修改，两方法一致并在正式训练前记录。

条件为 o[t-1],o[t]，预测 a[t+16]，执行前 4 步再观测；起点 padding、尾部 valid mask 和不跨 episode 的规则复用。

同任务两模型共享 train20、初始权重、窗口采样序列、diffusion timestep/noise RNG 流、optimizer、EMA 和训练预算。

训练、dev、test、视频 RNG 独立。改变可视化不能改变训练轨迹。

训练前允许每个正式配置最多一次 200-update 的 debug smoke run；模型/optimizer 不能用于正式初始化。合计最多 800 debug updates，另记成本。只用于检查有限数值、恢复、解码与闭环接口，不要求 smoke 已学会任务。

正式从头完成四个 20k run。不要为了短测成功减少正式预算，也不要自动增至更多 seed 或更大数据量。

8. 必要的校验：优先复用，不建立庞大测试工程

正式训练前验证以下关键风险；已有可信测试能覆盖时复用。

几何：正负 yaw、原点不漂移、真实 handle/FK goal 正确、关闭和成功状态能区分、零动作不成功。

专家：新 yaw 和固定物理目标上实际可执行；动作标签等于真实 env.step 输入，obs 没有被原地修改。

信息：world/frame 输入同维且信息来源相同；观测正逆变换可恢复。四元数按旋转矩阵等价比较，不能将 q 与 -q 误判为不同姿态。

动作：正逆变换恢复，特意测试局部某分量>1 的合法世界动作；通过变换再解码的专家标签应重放同一物理轨迹。

时间：历史使用正确时刻的 h；修改未来数据不能改变当前条件或 frame；chunk 解码不读取未来状态。

切分：yaw/位置实际覆盖、所有 train20 ID、normalization 来源、snapshot 分组与 split 隔离。

恢复：完整模型/optimizer/EMA/RNG 和动作采样恢复，旋转根节点/目标/mocap/历史/TimeLimit 都能重建。

数据审计：完整重放新 train20×2=40 条示范；测试 snapshot 至少检查全部初始状态的几何与 reset，再抽取正负 yaw 的短重放。

准备小量典型 debug 视频，检查门/抽屉是真的沿物理机构运动。视频不能替代数值验证。

发现 bug 后重做受影响检查，正确性足够后继续正式执行。不要用可逆性测试证明整个物理任务具有旋转对称性。

9. Checkpoint 选择和正式评测

5k/10k/20k EMA checkpoint 均在相同 dev20 上评价。依次按成功率最高、成功 episode 平均首成功步最少、checkpoint 最早选择；全失败时选最早。先冻结所有模型的选择，再运行最终测试。

主要终点：yaw near/mid/far 三个 split 等权汇总成功率，并分别展示各档、正负方向结果。

次要终点：IID、位置 OOD、combined 成功率；首次成功步数；进度；失败类型。

每个 episode 按第 2 节 success/终止规则结束；chunk 执行中触发后立即停止，不执行剩余动作。

每个正式模型测试 120 episode，四模型共 480；所有失败、超时、异常保留。异常单独标记并计入总分母，不删除后重新计算成功率。

记录 snapshot、模型/数据 hash、采样 seed、真实位置/yaw、关节进度、首成功步、终止原因和动作裁剪率。

仿真数值错误需要修复时，明确原记录和受影响重评范围；修复之后不能把旧结果覆盖成从未发生。

10. “好在哪里”的诊断

无需训练阶段分类器。利用只用于评测的模拟器信息，分开记录：

到 handle 的最小距离；

是否曾发生指定 gripper geom 与 handle geom 的直接物理接触；

最大关节 progress、最终 progress、是否达到 progress>=0.10；

首次接触、首次明显打开和成功的时刻；

实际首成功步数和最终动作裁剪比例。

接触必须依据已映射的碰撞 geom ID，而非只凭距离称“建立了接触”。距离和接触是不同诊断。初始接触排除 self-contact；报告所用 geom 名称。若无法可靠读取接触，保留距离和关节进度，并把“接触建立率”标为不可用，不能阻塞整个实验。

可据此描述：没有接近、接近但未发生目标接触、接触后无明显进展、有进展但未完成。不要仅据相关指标宣称某阶段机制被证明改善。

保持主要成功率指标；完成时间在成功子集上条件统计，失败时不能直接横比两种方法的成功子集均值。另绘制所有 episode 的限时成功比例曲线，失败在全时限内保持未完成。

最少图：

IID/位置 OOD/yaw OOD/combined 成功率；

near/mid/far 的成功率与角度范围，显示正负方向；

world/frame 的物理打开进度及主要失败诊断；

训练/dev 曲线；

所有 episode 的限时成功曲线。

训练扩散 loss 仅用于数值与优化诊断，不据不同动作表示下的 raw loss 大小直接宣布策略更好。

固定视频选择规则：每任务 IID 和 yaw-far 的第一条成功/失败（若存在），以及第一个 world 失败且 frame 成功的配对 episode（若存在）。同一初始状态两模型并排或相邻展示。无对应 episode 就记录 absent，不另挑“看起来最好”的视频。渲染失败时继续数值评测并记录。

四次正式训练和 480 个测试 episode 是否真的完成？给出四行真实结果表，按任务列出各 split；不能用 debug 或仍在运行的结果冒充。

yaw 变化为什么在物理上有效，专家在同一分布表现怎样？实际采用哪档角度，为什么？

两方法信息、数据和预算是否一致？相对 Round 1 改了哪些环境/归一化/动作裁剪设置？

当前结果属于人工正确元数据下的干预验证，不是 Agent 能力、视觉识别、组合能力或严格全系统等变性的证明。

本轮使用带方向的、信息保留的坐标参数化与显式动作解码；它不保证网络完全忽略世界位置。固定末端朝向也使整个机器人—环境系统并非精确旋转对称。

固定 20 demos 的比较支持有限数据下的泛化观察；完整 data efficiency 需后续多数据量曲线。一个训练 seed 不能证明跨 seed 稳健。

如果四个模型再次饱和，完整报告难度曲线和可行范围，说明这一干预/测试仍缺少区分度；若都差，区分训练分布没学会、专家/物理限制、OOD 失败和实现问题。开发阶段可以根据这些结果提出更合适的任务变化，但不要在本轮暗中滚动替换最终测试或无限重训。真实 bug 的修复始终允许，受影响数据与 run 必须明确版本和实际成本。
