# 开发规则

本文件约束新增接口和后续开发；历史实验源码及其既有行为保持不变。

- **No ad hoc**：不添加临时拼凑、针对个别样本或结果的特殊逻辑。
- **No heuristic**：不新增启发式规则，不猜测观测、动作、硬件语义或缺失参数。
- **No error handling**：不添加异常捕获恢复或自动重试。保留明确的契约检查，异常直接向调用方传播。
- **No fallbacks**：不提供备用模型、备用后端、默认伪数据或静默替代行为。
- **Always use Pixi**：所有 Python 和项目命令必须通过 `/home/users/oscar/.pixi/bin/pixi run ...` 执行；ManiSkill 使用 `pixi run -e round4 ...`。不创建 Conda/venv，不使用裸 pip。
- 允许按实际需求修改 Pixi 配置，但须保留历史依赖与来源记录。新增接口优先复用现有环境。
- 测试仅可使用物理 GPU **0、1、2、3**；保留无关进程，不向 GPU 4、5 分配工作。
- 无法获得准确接入信息时，保留空的抽象接口；不模拟已经接通的硬件或 API。
- 保持先验提取的证据、方案冻结、实现审计、训练、开发选择和锁定测试流程不变。
- 保留冻结数据、配置、历史源码和运行产物；训练、评估、API 或硬件接通的完成声明必须有实际验证证据。
