# Door implementation audit

The original proposal was saved before shared source/interface inspection. No substantive feasibility revision was needed. Implementation is confined to `src/round3/door_plugin.py`; candidate configurations are `round3/configs/door/P1.json`, `P2.json`, and `P3.json`. Shared learning/plugin/model/dataset files were read but not edited. No expert/reward source, larger demonstrations, old run results, or concrete development/test states were consulted.

P1 implements the specified 55-dimensional conditioning, all-dimension passthrough normalization, cabinet-axis action encoding and inverse decoding. P2 implements 43-dimensional conditioning and 12 joint action/future channels. P3 combines P1 conditioning/actions with P2 future targets expressed in the current cabinet frame. The auxiliary epsilon mean squared loss has fixed weight 0.2; shared base action epsilon loss remains weight 1.

The shared inherited Policy hardcodes a four-channel sampling tensor. A plugin-local DoorPolicy subclass changes only allocation to config.action_dim while retaining exact unbounded DDIM sampling. P1 sampling was checked for bitwise equality to inherited Policy under identical weights and CPU generator. All candidates use the frozen scheduler and no local action clipping; action_decode discards future channels and leaves world clipping to shared deployment.

Run `/home/users/oscar/.pixi/bin/pixi run python round3/design_records/door/audit_plugin.py` from the repository root. The resulting artifact `round3/audits/door_plugin_v1.json` records proposal/plugin hashes and validated checks on exactly the two bundled trajectories (220 windows), synthetic geometry inputs, and untrained networks. Checks cover fixed normalization, two-frame current-anchor rotation, all valid next-state labels, terminal labels and zero tail padding, exact loss weighting and masked gradients, action inverse error, parameter budget, finite forward/backward gradients, and complete 16-step inference shapes/timesteps. No optimizer updates, trained checkpoints, evaluation episodes, or outcomes were used.

Measured trainable parameter counts: B0 4,710,980; P1 4,811,332; P2 4,728,908; P3 4,814,924. Maximum world action encode/decode roundtrip absolute error was 1.7881393432617188e-7. All audit assertions passed. Formal training and rollout evaluation remain the coordinator's work; this audit does not claim task success.
