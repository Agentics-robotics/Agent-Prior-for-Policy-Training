# M0 设置对照：为什么修复后 ID 成功率仍低

状态：2026-09-15 本轮设置对照与独立确认全部完成。新增 3 个训练模型、180000 次优化器更新、56 次真实策略评估；完整记录见 [summary.json](../../runs/exp2/m0_setting_study_20260915/summary.json) 和 [results.csv](../../runs/exp2/m0_setting_study_20260915/results.csv)。第一阶段的修复及历史失败见 [M0_DIAGNOSIS.md](M0_DIAGNOSIS.md)。

**主要结论：M0 已经有非零成功，但仍不是可靠的基线。** 120 条数据模型在五次开发比较中为 4/5，在独立确认中只有 **5/15（33.3%）**；12 条基线在同一确认批为 **4/15（26.7%）**。十倍数据只多成功一例，没有可靠提升证据。DDPM200、较短执行段和简单放宽终点容差也没有解决问题。本次没有豁免原正式门槛，没有推进 M1/M2。

## 问题和判别方法

原模型修复观测缩放并使用完整 DDPM100 后，12 条示范、60000 次更新在独立 ID 开发初态上成功 2/5。三个失败都没有把红块从抽屉中抬起。需要解释的是抓取阶段的闭环泛化，而不是训练 loss 是否下降。

| 可能原因 | 控制实验 | 能回答的范围 |
| --- | --- | --- |
| 数据覆盖不足 | 同一原生采集器、同一 ID 分布，12 → 120 条示范 | 固定优化预算下，增加成功示范是否改善；不是增加恢复示范 |
| 绝对关节目标难以精细预测 | 相对于当前观测关节位置预测整段目标，最后还原为原生绝对命令 | 动作坐标和数值尺度的影响；控制器、网络与任务不变 |
| 反向扩散不够细 | 100/100 → 200/200 个训练时间点/推理步 | 完整扩散配方的影响；不是给旧 100 时间点检查点强加 200 步 |
| 动作执行期间反馈太慢 | 冻结基线 DDPM100 权重，每次执行 8 → 4 个动作 | 重新规划间隔 .4 → .2 秒，单独检验反馈频率；没有重训 |
| 初态变化范围超过模型能力 | 冻结原模型，红/蓝初始 XY 变化缩至 25% | 对较窄初态分布的敏感性；不能冒充原 ID 提升 |
| 终点判定过严 | 已有轨迹离线复算，红块垫子半宽 .06 → .08/.12 m | 只改终点横向容差，保留高度、释放、退开、稳定和连续 10 步；不改变抓取物理 |

固定网络为同一个 16,998,408 参数 U-Net；模型 seed=0，每组 60000 次更新、batch=128、余弦学习率、500 步 warmup、EMA=.999，均取最后 EMA。除目标变量外，使用已经修复的观测归一化、原生场景和成功判定。没有新技能、规则控制器或 API 候选模块。

## 已有证据

1. **放宽终点横向容差没有改善：仍然 2/5。** 两种放宽设置都如此。逐步复算原始成功判定与记录完全一致，说明没有另一个离线判定器造成差异。证据见 [offline_analysis.json](../../runs/exp2/m0_setting_study_20260915/offline_analysis.json)。这不等价于检验更大夹爪或更容易抓的物体。
2. **ID 是相同采样分布，不等于示范覆盖充分。** 当前只有红块 XY 各 ±1.2 cm、蓝块各 ±1.5 cm 的变化，机器人和抽屉初态固定。物理范围不大，但仍是四维组合；一条约 1065 步的轨迹并不提供 1065 个独立初始布局。
3. **全任务成功率会累积多个接触阶段的失误。** 开抽屉、抓红块、放红块、抓蓝块、放蓝块依次依赖前一步。训练分布中的低动作误差不能保证偏离后的恢复；当前示范只提供成功轨迹。这是待实验细化的机制解释，不是已测得的独立阶段概率。
4. **缩窄初态不是完整解法。** 冻结同一模型、同一五个策略随机种子，初始位置变化缩至 25% 后为 3/5；原 ID 为 2/5。6001、6003 在窄范围仍失败；6002、6004 由失败变成功，6003 由成功变失败，说明结果不是单调的“越接近中心越容易”。样本太少，不据此宣称稳定的 20 个百分点改善。
5. **闭爪位置存在具体的物理偏差。** 用统一的事后诊断条件（抽屉 > .26 m、红块 z < .08 m、TCP 距红块 < .08 m、夹爪命令 < −.5）定位第一次闭爪：12 条原示范 TCP 相对红块 X 偏移为 −8.74～−8.84 mm；失败初态 6001/6002/6004 为 −31.61/−26.04/−32.64 mm。6000 在 −24.19 mm 时闭爪但最终成功，6003 为 −9.94 mm。因此它是接触偏差的证据，不是一个可据此确定成功的万能阈值，也不能把全部偏差直接归给某一帧的网络误差。原始数值见 [first_red_close.json](../../runs/exp2/m0_setting_study_20260915/first_red_close.json)。
6. **初态 ID 不保证后续状态仍有训练覆盖。** 初态相同分布只是起点条件；开抽屉后的回弹、物体滑动、接近路线偏差都由策略自己的动作造成。原示范第一次闭爪的红块 X 范围约 −.210～−.195 m，6001 当时为 −.182 m；6004 红块位置在该范围内却仍抓偏，故“数据初态覆盖”也不能独自解释所有失败。

新增反馈频率对照在新模型评估前记录于 [feedback_frequency_addendum.json](../../runs/exp2/m0_setting_study_20260915/feedback_frequency_addendum.json)。原轨迹空夹闭合约需 3 个动作（.15 秒），短于原本 8 个动作（.4 秒）的反馈间隔；因此单独测试反馈频率，最终负结果也完整保留。

## 如何理解这些结果

**最有直接证据的是闭环接触偏差。** 输入和动作接口能正确回放；修复后基线的观测没有再次出现原来的归一化爆炸，但闭爪位置仍能偏离示范约两厘米，抓空后也不会纠正。因此“初态在 ID 范围内”与“策略以后遇到的状态都被示范覆盖”是两回事。DDPM 学到的是示范条件下的动作分布；多做去噪不能自动补上未学过的纠正动作。

**当前数据的限制不只是条数，也包括覆盖的行为。** 原生采集器在固定路径规划和接触动作下生成成功示范，抓取失败会终止，而非演示怎样从抓偏、抓空后恢复。120 条扩大了布局和成功路径覆盖，但仍不是恢复示范。十倍数据在独立确认中只净增一例，说明“继续增加同类成功示范就会解决”没有得到支持。闭环状态覆盖不足是目前最符合轨迹证据的机制解释，尚未通过恢复数据的直接干预证明它是唯一原因。

**优先保留原任务精度与 DDPM100/执行 8 的配置。** 放宽终点横向容差没有救回失败；DDPM200 的成功数未增加，推理成本约翻倍；执行 4 反而为 0/5。更频繁重新采样还会改变动作连续性，不能把它简单等同于“更精准”。具体为什么这一设置变差，尚未由独立的采样连续性干预证明。

**网络和优化预算仍有判断边界。** 同一个 17M 参数网络已能完成整条任务，故没有必要先把“网络太小”当作事实。此次固定 60000 次更新来比较数据量；120 条的每条示范平均曝光少于 12 条，因此该对照回答的是固定计算预算下增加数据的效果。没有单独比较更大网络或更多优化更新，不能排除它们继续改善的可能。去噪步数与优化器更新数是两个不同变量。

下一步若继续改善，值得优先研究的是**接触前后偏离正常轨迹时的有效状态覆盖和纠正示范**，以及更充分优化能否提高这些状态下的控制质量；这是根据失败机制提出的后续方向，尚未在本次训练中验证。没有据此给策略添加规则、技能或新的神经模块。

## 判定精度：一个额外姿态要求，不是大多数失败的来源

120 条模型的确认初态 6014 已满足物体占据、稳定、TCP 退开等全部其他条件，最长连续 310 步；但手指没有同时张开到每侧 .035 m，故原判定仍失败。其他条件通过时，手指最小开度最高约 .028 m，最终空手闭合为 0。

这符合现有协议的实现，但“最后手仍必须张开”与“物体已放下且手已离开”不是同一个要求。如果研究目标只关心交换完成，可以在未来协议中明确是否需要这个额外姿态。这里仅离线去掉最终开指要求，保留位置、完整占据、TCP 距离、稳定和连续 10 步：120 条模型 **5/15 → 6/15**，基线仍 **4/15**。没有修改原成绩或判定器。因此它值得澄清，但不能解释大部分失败。证据：[final_hand_posture_6014.json](../../runs/exp2/m0_setting_study_20260915/final_hand_posture_6014.json)、[offline_analysis.json](../../runs/exp2/m0_setting_study_20260915/offline_analysis.json)。

## 原来的输入放大问题是否复发

原基线、120 条模型和 DDPM200 的五次开发轨迹，归一化观测峰值约 1.43；动作增量的开发峰值约 1.57。完整 15 次确认中，120 条模型峰值约 **1.76**，12 条基线约 **7.87**。没有复发原来的四元数数百倍放大，但较长评估仍出现超出训练范围的动态观测，不能宣称所有输入始终在训练分布内。原始 12 条示范和原五个开发轨迹也未发现相邻帧等价四元数的符号翻转，见 [quaternion_sign_audit.json](../../runs/exp2/m0_setting_study_20260915/quaternion_sign_audit.json)。

执行 4 的失败对照有一个不同问题：6004 在第 335 步之前的观测中，右指关节速度达到 5.837 m/s；训练归一化中心 −.059、尺度 .259 m/s，归一化为 22.75。它首先在第 321 步超过 5，早于第 1105 步的红块闭爪。这不是再次除以 .001，而是该执行设置下出现了真实的大速度和偏离训练分布；仅凭该峰值还不能确定失稳的唯一首因。证据：[execution4_outlier.json](../../runs/exp2/m0_setting_study_20260915/execution4_outlier.json)。常用执行 8 配方没有这一级别的输入异常。

## 时限与接触复现的附加诊断

动作增量模型五次原任务结果为 2/5。6003 已搬好红块并抓起蓝块，蓝块到目标的距离在第 900/1100/1300/1500 步分别约 .384/.320/.266/.242 m，表现为缓慢搬运，不能归为抓空。

为检验时限，预先另定 3000 步上限、同一模型和 seed=6003，复测在 1663 步成功。但严格前缀核对发现：初始观测和前 433 步状态/动作完全相同，第 434 步红块接触后物理状态开始不同，当时红块位置最大差约 .38 mm、姿态差 .0222 rad；策略动作到第 440 步仍相同，第 441 步重新规划后才不同。

因此复测不是原轨迹的位级延续。它说明该模型有完成较慢轨迹的能力，不能单独证明原失败只因时限，也不能替换原来 1500 步的失败。具体模拟器内部状态/接触求解与重置历史的原因未定位，没有修改物理实现或自动重抽。证据：[time_limit_addendum.json](../../runs/exp2/m0_setting_study_20260915/time_limit_addendum.json)、[extended_time_prefix_audit.json](../../runs/exp2/m0_setting_study_20260915/extended_time_prefix_audit.json)。
