# Grasp-frame transport with explicit detachment

Policy: `deliver_disengage__h01`  
Skill: `deliver_disengage`; assigned heuristic 1; M1_v2.

## Original hypothesis (unchanged)

The assigned statement is: "Grasp-frame transport with explicit detachment: while grasped, the block and TCP approximately share a rigid transform, but that dependency must end at release. Hypothesis: diffusing the desired object trajectory and compensating the measured grasp offset improves goal placement and prevents inconsistent wrist/object motion."

The supplied heuristic, expanded segmentation, and handoff identity are retained. The following are implementation choices and limitations, not edits to that hypothesis. This is a learned action diffusion policy, not a controller assembled from poses, an action replay, or a schedule over source indices.

## Executable adaptation of the proposed two-level diffusion

The public sampler has exactly eight diffused coordinates: seven absolute joint targets and a gripper command, with horizon 16. It has no extra latent-pose sampling interface. Consequently this implementation does **not** claim a separately noised and sampled object/TCP DDPM. Instead, it implements an **action-indexed geometric reference denoiser** inside each action epsilon evaluation. Given the current noisy action trajectory, noise timestep, and causal observations, it predicts clean future object and TCP references. Their clean-state reconstruction losses are evaluated at every sampled action-noise level. These trainable references condition the learned action DDPM and are recomputed throughout reverse diffusion. Thus the same sampled action hypothesis indexes the high-level references and their low-level decoder; no teacher-forced future reference ever enters forward.

This preserves the central representational and detachment hypothesis, but does not reproduce an independent hierarchical pose sampler. It also avoids the poorly conditioned division by sqrt(alpha_bar) that would arise from penalizing a high-noise action x0 estimate. There is no analytic IK or FK provider. The action U-Net learns the reference-to-joint relation by demonstrated action denoising. Geometry consistency in the reference latent is not a guarantee that a predicted joint action realizes that pose physically.

The heuristic's semantic carried/requested/next IDs are not arguments of the actual forward interface. Rather than silently fabricating an ID or a phase clock, the network retains two ordered object streams (red, blue), each with its own pose and goal. It infers attachment and local intent from world state and goal residuals. The inference agent should nominate this policy only when the observed context is compatible with the requested delivery. Contradictory explicit object requests cannot be communicated through this API. Both streams remain present in red-to-blue overlap, so readiness of red need not erase the context needed for an empty approach to blue.

## Architecture and grasp representation

1. The provided shared range normalizer normalizes the two raw 47-dimensional observations, with no clipping or scale refit. The encoder also receives their normalized difference and, for both objects at both times, the measured transform B = inverse(T_tcp) T_object and world goal-minus-object translation. This makes 181 features. All derived translation features use the supplied complete-demonstration TCP XYZ half ranges; quaternion components use unit bounds. These are not tiny per-skill empirical scales. Keeping world pose, Z, goals, and all robot joint state deliberately avoids a false full rigid-motion-invariance claim.
2. A 256-wide MLP predicts a three-way causal mode distribution (free, red-attached, blue-attached), and learned two-time softmax filter weights for each object's B. Translation is averaged; relative quaternions are sign-aligned to the latest observation then normalized after weighted averaging. The offset is measured, not replaced by a nominal zero or a stored demonstration offset. The filter has two observations, no persistent hidden state, and does not claim long-horizon slip estimation.
3. A 128-channel temporal reference network consumes noisy actions, learned horizon-slot embeddings, a 64-dimensional sinusoidal timestep embedding, and the causal context. Four residual convolution blocks have dilations 1,2,4,1. Its 21 outputs per slot are two object translation/rotation increments (12), a free TCP increment (6), and three future mode logits. Positions are increments from the current measured poses. A local orientation increment is represented as the unit quaternion normalize([1,r_x,r_y,r_z]) and composed with the current quaternion. This is appropriate to the modest orientations in these demonstrations, not unrestricted contact reorientation.
4. For each object, the measured filtered B gives the candidate TCP reference T_tcp_ref = T_object_ref inverse(B). This is full quaternion/translation composition, not driving TCP to the object's pad center. Candidate TCP references and the independently predicted free TCP are softly blended. An object's blend mass is its predicted future attachment probability times its current causal attachment probability. Remaining mass uses the free branch. This availability gate matters: if closure is only predicted to occur later in a chunk, the current open-approach separation is not yet a valid grasp offset. The free branch handles that crossing until the next observation refreshes B. Similarly, a predicted release reduces future coupling even before a new observation confirms open fingers. Gates are learned soft probabilities, not hard safety switches.
5. Both predicted object goal residuals and increments, object orientations, the blended TCP and free TCP references, and future modes form 37 features per slot. A learned sequence compressor, history context, current modes and filtered offsets produce a 384-dimensional condition for the public Conditional U-Net. It predicts all eight action epsilon coordinates. Its widths are 128/256/512, timestep embedding 128, kernel 5, groups 8. Raw state access is retained rather than enforcing a brittle bottleneck.

Inference uses the fixed 100-step DDPM, affine action decoding, sample clipping, horizon 16 and execution prefix 8 supplied by the framework. The model does not inspect source index, trajectory ID, future observations, or completion labels at deployment. Both encoder branches, including the geometric branch, are trainable. No image processing, external tool, or nonlearned action construction occurs inside the model.

## Training labels, losses and gradients

Let M denote the applicable validity mask, S the shared TCP position half ranges, and Q(a,b) = max(0,1-dot(unit(a),unit(b))^2). All vector position losses below are means of squared coordinate error divided by S; quaternion losses are sign-insensitive. Validity weights are normalized with a denominator floor of one. Future slots correspond to the states **after** action slots t-1 through t+14, as provided; targets are not shifted by another step.

Attachment pseudo-labels are constructed only in compute_loss under no_grad. For each object, the score multiplies:

- sigmoid((0.027 - mean physical finger position)/0.0015), in metres;
- sigmoid((0.045 - TCP/object distance)/0.005);
- a relative-transform stability factor, sigmoid((0.012 - relative translation drift)/0.002) times exp(-relative quaternion error/0.01).

A later masked future height exceeding both the present height by 0.006 m and 0.035 m can confirm the stability term at a just-closing grasp. It cannot bypass the closed-finger or nearness factors. The two object scores are normalized if necessary, remaining mass is free, and 1e-4 smoothing is applied. These are deliberately approximate successful-demonstration labels, not calibrated force/contact estimates. The future sequence uses adjacent target states for co-motion, with the older causal state preceding slot zero. Future confirmation is training-only. No observed action command or future pose feeds deployment mode prediction.

The total objective is:

`L = L_epsilon + 0.4 L_reference + 0.1 L_attachment + 0.06 L_rigidity + 0.03 L_offset + 0.005 L_continuity`.

- **Action diffusion:** the public masked action epsilon MSE. Gradients train the U-Net and, through its learned condition, the history encoder, offset filter, mode heads and reference network.
- **Reference reconstruction:** masked position MSE for both objects plus the blended TCP plus 0.3 times the free TCP. Add 0.05 times the sum of their quaternion errors, with free-TCP orientation also weighted 0.3. Targets are actual future poses, not hard-coded straight lines or forced pad-center trajectories. All phases, including stationary predecessor objects during empty motion, receive this supervision.
- **Attachment:** soft-label cross entropy for the current mode and the masked future mode sequence. Gradients train mode heads and their shared networks; observed-only pseudo-label computation is not counted as a trainable penalty.
- **Rigidity:** form a predicted relative transform from the **independently predicted free TCP** and predicted object pose, and compare it to the filtered current B. Penalize normalized translation error plus 0.1 quaternion error. Use only valid slots where both current and future pseudo-labels for that object exceed 0.8. This is not the identically zero equality obtained by checking the algebraically coupled TCP. Gradients reach the two predicted trajectories and learned filter. It supplies no rigid penalty for detached retreat or an object only about to be grasped.
- **Offset filter:** compare the learned filtered B with future measured B, using the same held mask and translation plus 0.1 quaternion metric. This trains temporal weighting, not a constant observed-pose penalty. When the two causal transforms are identical it may have zero local gradient; other prediction objectives remain differentiable.
- **Orientation continuity:** modest adjacent predicted orientation penalties for both objects and blended TCP, masked by both neighboring future-valid flags. There is no forced upright goal and no new task predicate.

The geometry and mode losses explicitly depend on predictions. Their gradients do not pass through future label generation. The primary action objective is never replaced by a geometry-only loss. The reference objectives shape action generation through conditioning, but there is no separate frozen dynamics predictor or guaranteed action-space physical constraint.

## Handoff and selection guidance

Accept the full demonstrated incoming transition, including open fingers near a low block, ongoing closure, partial lift or elevated transport. Continue from live observations; do not initialize an attachment simply because the selected skill is delivery. During held transport maintain the nominated object's own goal context and measured offset. During lowering the object may enter its pad before fingers open. If subsequent manipulation is needed, continue opening and separation; the free branch learns retreat and the high empty red-to-blue approach over the entire outgoing overlap. Red remaining still while TCP rises is the observation cue that rigid coupling should cease.

The successor should receive raw world poses, both goals, qpos/qvel and two causal observations, with red as predecessor and blue as requested object in the inference agent's semantic context. An optional inferred attachment estimate is not a mandatory hidden state. A successor supporting the same loaded overlap may take over before red is released; otherwise use the clearer open, separated, high approach state. At the blue terminal exit both goals should be checked against the contract; disengagement is separately useful, not a required additional hold.

Task success remains full rotated XY containment for each 0.02 m half-size block inside its own 0.06 m half-width pad, centers targeted at red (-0.18,-0.25,0.02) and blue (-0.18,0.25,0.02), with z tolerance 0.011 m and one required observation. No drawer, gripper-release, TCP-clearance, speed or sustained-hold predicate is added. The network does not implement a hard corner-containment constraint or a predicate-reporting API; the inference/task evaluator uses live observations for those checks.

## Dependencies, limitations, and falsification

Implementation uses only Torch, math and appl.public. Training remains seed 0, 20,000 updates, batch 128, AdamW 1e-4 with weight decay 1e-6, gradient norm 1, 500-step warmup and cosine schedule, EMA 0.999, final-budget EMA selection. No rollout-performance feedback or hyperparameter search is used in this design session. Interface checks test computation, updates and reload, not task success.

The demonstrations support approximately rigid top-down transport after successful closure. Compression, small slip and pose noise motivate soft coupling. Actual failure recovery, force/friction identification, rolling/deformable grasps, arbitrary reorientation and contradictory object requests are outside validated support. With only two states, a quiet closed grasp at the table can be ambiguous; mode labels are weak supervision. Quaternion averaging is a local approximation, and no global SE(3) equivariance is claimed. Soft mode gates can be wrong; reference rigidity does not prevent real drops or collisions. Shared TCP scaling is a numerical convention, not an invariance mechanism. The direct state path may let the action denoiser ignore some reference information.

Appropriate future tests are a parameter-matched raw-state action DP, removing offset compensation, and removing attachment/release gating separately. Evaluate object-versus-TCP placement error, relative-transform stability, release-following behavior, and full expanded-slice handoffs, not only steady-state transport. These comparisons are proposed, not performed or claimed. A drifting B during claimed attachment, object descent while TCP stays high, or block motion with the retreating wrist after predicted detachment should prompt reassessment rather than an untested automatic recovery claim.
