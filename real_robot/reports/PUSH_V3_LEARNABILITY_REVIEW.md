# training_v3 可学性与调用一致性审阅

核对日期：2026-09-21。范围是读取冻结代码、已有预处理统计和训练日志；没有新训练、
模型评估、API 调用或机器人动作。科学源码和权重未改动。
[数值与源码哈希](PUSH_V3_LEARNABILITY_FACTS.json)。

判断：训练动作拟合已经改善，但现有证据不足以支持可靠长时序操作和新形状泛化。
预计相似场景中的局部动作比任意新布局/新形状完整任务更有希望；这是代码与数据分析，
不是实测性能排序或成功率。

## 已有学习证据

对训练日志中步骤 100–1000、19100–20000 各十个记录批次的 BC 分量取均值：

| Policy | 早期 BC | 后期 BC |
| --- | ---: | ---: |
| tool_waypoint_v1 | 0.0343761 | 0.0000313 |
| piece_contact_graph_v1 | 0.0654625 | 0.0045995 |
| piece_goal_field_v1 | 0.0680883 | 0.0061370 |

它们是不同、重复采样的训练批次，不是独立验证集，也不是最终 EMA 的任务成绩。
重载误差为零只证明加载一致。两条原始示范、四个工具片段、二十二个物体调用不能
按相邻帧数当作独立场景数量；已有证据不能判断泛化误差或新目标响应是否正确。

## 具体约束与风险

1. **训练/默认调用的工具目标条件不同。** `data_pipeline.py` 为整个搬运片段传入末行
   TCP pose 和末行动作作为目标条件；`geometry.features` 将 TCP 目标误差和 terminal
   输入网络。在线 `policy._act` 缺省 `exit_tool_base` 为调用开始 TCP，terminal 缺省零。
   该条件差异是代码事实；模型对它的依赖程度尚未通过消融测量。显式 exit 可以传入，
   但仍需核对训练与部署的语义和覆盖。即使缺省 exit 不作为完成条件，它仍进入模型输入。
2. **接触几何未落到实际杆尖/物体表面。** 默认 W 来自标定板，30 mm 是设计余量；
   TCP 不等于已标定杆尖。候选接触位置、距离和高度因而是代理量。感知目前依赖颜色和
   因果轮廓跟踪。强几何 prior 的效果取决于这些基础量是否正确。
3. **六维动作和混合阶段仍在。** 所有模型的五个 mode 都有六维残差；搬运模型保留
   接近、推、重接触和退出。正向法向候选与残差范围限制并不强制最终动作纯二维。
   因此仍需从少量轨迹学习接触阶段/高度/姿态调整以及切换。
4. **阶段是弱标签。** 搬运 15,765 行中 approach/contact/reset/exit/hold 分别为
   5,171/2,272/1,024/6,342/956。非零动作且轮廓误差小于 12 mm 就优先标为 exit，
   不能由这个名称推断工具正在退出；接近目标的微调也可能满足此规则。40.2% exit 的
   比例本身不证明错误，需要视觉/几何核对。工具标签只有 approach/reset/hold。
5. **goal 和接触监督未经人工核验。** 目标取片段末尾跟踪轮廓；600 条缺少可信物体
   目标但保留动作监督。graph 的接触标签取距离 TCP 最近的轮廓节点，不是实测接触点；
   学习的 response 是跟踪产生的弱位移。小辅助误差不能证明接触机制正确。
6. **局部相对表示未构成严格不变性。** 当前地图以物体/TCP 为中心，但保留关节状态、
   末端姿态、全场景占据等信息；没有硬性的 SE(2) 等变结构或已核验物理增广。
   因而存在学习示范关联而非目标驱动规律的可能，需未见目标/布局检查。

## 下一步应验证什么

优先核对若干关键推、换边、微调片段中的 mask、杆尖、平面和弱阶段标签；统一训练与
调用的目标语义。用固定当前观测、改变合法目标的诊断检查是否对目标作出合理响应；
该诊断只说明目标响应，不替代闭环评估。随后在已接通并核验的控制器条件下，分开评估
熟悉物体的新起点、新布局及未见物体。任何离线划分应按原轨迹/物理实例分组，避免
重叠 cuts 和相邻帧同时进入训练与测试。不要因本次阅读自动发起新实验或修改冻结模型。

针对稳定平面推阶段，减少可学习动作维度、明确入场条件和换位交接是合理的下一轮
设计方向；须以真实接触高度/姿态支持为前提。图像输入本身并不妨碍这个方向，二维
输出本身也不能修复感知或接触平面错误。

## 输入容量、TCP 目标与历史条件追加审阅（2026-09-21）

用户进一步询问输入维度是否导致过拟合，以及训练和调用的 TCP/历史输入差异。
[只读测量记录](PUSH_V3_INPUT_CONSISTENCY_AUDIT.json)记录模块参数、原记录时间间隔、
各片段末行动作和一个具体 TCP 目标对照。仅在 CPU 实例化结构计数，未执行模型推理、
训练或机器人动作；四个科学源文件哈希与前次审阅一致。

四时刻几何图包含 131,072 个标量，但每帧经共享 CNN 编码为 192 维；状态同样编码为
192 维，再经共享 GRU。参数风险不能按原始像素数直接判断。每个模型 map_encoder
375,808 参数、state_encoder 58,752、GRU 332,928，而 core 有 1,148,928 参数。
工具/目标场模型共 2,005,168 参数，接触图模型 2,147,601。只删掉 state 的 21 维
零填充会减少首层 4,032 参数，不能解决有限示范覆盖问题。两条原轨迹、四个工具片段
和二十二个搬运片段的相邻记录不能当作大量独立任务。容量和示范相关性造成显著过拟合
风险，但尚无独立评估证明已发生过拟合，更不能断言只能过拟合。

TCP 差异指额外的工具目标条件，非已发现实测当前位姿格式不一致：训练用片段终点
T_base_ee，搬运在线缺省 exit_tool_base 使用调用起点 T_base_ee。该目标的位移/旋转
误差进入 state[64:70]，且几何退出分支的 route 也直接使用该目标。a_l_move 若从
监督起点发起默认调用，其入口和示范终点 TCP 平移位置相差约 23.9 cm。
显式传入 exit_tool_base 可以消除缺省定义差异，但任意新退出目标的可学性仍无证明。

另一个条件是 terminal_twist：训练使用片段最后一条记录命令，在线省略则置零。
原始末行动作中工具 4/4、搬运 20/22 非零；这些是 cut 终点，不能自动当作停稳终点。
目标条件可以由未来示范生成作为训练标注，前提是线上具备同义、可指定且有覆盖的目标；
不能把这种用法一概叫作未来信息泄漏，也不能默认与当前在线契约一致。

历史索引两端都是 [11,7,3,0]，但训练按原记录行，线上按成功积累的 act 观测。
原始记录间隔中位数约 0.0333 s，最老时刻约 0.3667 s 前；如果线上是 20 Hz 或
5 Hz，对应最老历史分别约 0.55 s 或 2.2 s。模型没有显式历史时间间隔特征，不能只
依赖相同索引声称时间尺度一致。训练的上一条动作来自示范，在线需提供实际执行后的
last_executed_action；省略将置零。训练环境与策略自身执行形成的状态历史也可能不同。

历史有助于判断物体是否跟随末端移动，也可能提供复制前一动作的捷径；本次未测量
具体模型是否使用该捷径。背景依据：[Causal Confusion in Imitation Learning](https://proceedings.neurips.cc/paper/2019/hash/947018640bf36a2bb609d3557a285329-Abstract.html)、
[Fighting Copycat Agents in Behavioral Cloning from Observation Histories](https://proceedings.neurips.cc/paper/2020/hash/1b113258af3968aaf3969ca67e744ff8-Abstract.html)。

下一轮应先统一对象目标、退出/停止语义与历史采样，再评估是否压缩网络、只把必要的
机器人量放入学习分支，以及将平推组织成低维动作技能。保留完整机器人状态供执行层
核验，不要求所有状态都进入神经网络。上述为审阅建议，不是已提交的新 API 设计。
