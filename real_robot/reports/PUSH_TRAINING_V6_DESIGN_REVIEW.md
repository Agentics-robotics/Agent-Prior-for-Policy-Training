# Push v6 设计评价

审阅日期：2026-09-22。本文件是开发者对本轮代码的只读评价，不作为 Runtime API
输入，不构成新增模型设计或训练反馈。下述结构来自API最终提交
`6483209318...`；执行状态和数值见[训练完成报告](PUSH_TRAINING_V6.md)。

当前判断：这是一个有明确学习对象、小数据结构动机合理的局部接触选择器，
但已完成训练的接触标签拟合仍不够精确，尚未证明实用收益。
它把目标理解与排序交给 Agent，把到达和短推执行交给已有
planner/controller，网络集中学习物体几何、目标运动与接触/方向/距离的关系。
这部分关系确有用途：执行器知道如何到达指定接触，并不自动知道哪个接触会
使物体更接近目标。

当前网络为96个8维轮廓特征、864个20维候选特征，点编码器和候选评分器共享
参数，约18,497个可训练参数。SAM感知模型冻结。候选由96个接触点、3个 inward
heading和3个距离组合而成；候选数量不等于独立模型数量。局部坐标、目标方向
表示、平面短推输出减少了网络需要学习的变化；尺寸、工具半径和实际距离仍
保留，未把物理尺度完全抹去。模型不输出竖直位移或关节控制序列。

有条件的接触选择可提供实际价值，但当前训练是示范模仿，没有系统比较每个
未执行候选的真实结果。训练误差下降说明能拟合所构造的标签，不能单独证明
其选择比简单几何策略更有效。后续固定模型的闭环测试应观察每次短推后的
物体平移/转角误差变化、重接触次数和任务完成情况；这不是本轮已做过的评估。

最具体的风险是监督几何：接触点由图像轮廓、工具端点及不确定的几何重建
推断，方向/距离由记录运动推断。遮挡、物体粘连、孔洞遗漏、物体关联和图像
时序会影响标签。只对可信通道施加监督、把未知通道边缘化，较直接丢弃整条
数据或把缺失值设零更符合当前目标。其可用性仍依赖实际标签检查。

对原物体改变位置/朝向的泛化，当前表示有合理依据；相似新形状值得检验；
任意新字母、复杂内孔接触、新摩擦或厚度条件尚无充分证据。几百个重叠窗口
仍来自两条录像与同一批物体，不能当成几百种独立交互经验。不显式输入字母ID
也不排除网络记住已有几何形状。最终130例、9/12学习段，其中11例内孔接触，
115例完整监督和15例仅接触监督；A的open-corner/bar finish和B的loop finish无梯度例。
独立核对已确认A43/B87全部参与3000步训练，没有再保留大开发集。

最终训练集接触点与推断标签平均相距16.403mm，API汇总的行程差异2.101mm。
前者是候选选择差异，不是机器人控制误差；但在训练数据上已有此量级差异，
不能把“参数少、全部有效数据训练”直接等同于“已经学好”。多解、弱标签和
模型拟合均可能影响它，当前没有候选实际效果的闭环证据来区分原因。
模型重载误差零、9项API调用检查和独立worker检查通过，证明代码/权重可调用，
不证明几何选择有效。应把结构动机、标签可靠性、拟合程度、物理效果分别评价。

参考研究 [Transporter Networks](https://transporternets.github.io/) 在其任务上
展示了利用空间结构改善操作学习样本效率的价值。它支持上述设计方向的研究
动机，但其架构、数据和实测成功不能转移为我们这份模型的有效性证明。

本次评价不改变已执行的通用prompt、API代码、采样、训练或权重。
