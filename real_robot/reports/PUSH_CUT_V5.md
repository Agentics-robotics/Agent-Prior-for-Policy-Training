## Task interpretation (verbatim API output)

Build designs and exact source-preserving cuts for a reusable push-only library, not policies or robot execution. Inspected images show a rigid rod-like tool installed on the robot, not demonstrated grasping; missing gripper feedback is not used. Both episodes manipulate seven-looking flat wooden/cardboard-colored letter pieces on a table. Shape aliases include wedge W/M-like, O-like ring, R-like, D-like, L-like and two visually similar barred pieces. Character identities, target words and success are visual hypotheses only. Endpoint arrangements resemble lettering but cannot be promoted to verified requests or success annotations. Required deployment includes entirely unseen identities AND physical shapes, new words/layouts and new arrangements. The architecture explicitly separates open-world semantics, distinct-instance inventory, measured geometry, metric layout planning, local manipulation and sequencing. The current deliverable ends at dataset/heuristic/catalog publication and declares all later executable/perception/controller dependencies.

## Goal conditioning (verbatim API output)

Common conventions and label rules apply to all segments. Establish workspace W with origin the projection of the calibrated board origin onto a separately verified tabletop plane, z the plane normal pointing toward base +z, x the board x axis projected onto that plane, and y=z cross x. Positions are meters and angles radians; retain base transforms as recorded. The supplied board transform is an initialization, not proof of the tabletop or letter-top height. Goal G is an SE(2) rigid displacement of a selected physical instance's observed footprint, equivalently an explicit goal silhouette in W, plus a desired semantic orientation when distinguishable, position/angular or silhouette tolerances, protected-instance masks and optional exit_tool=(pose in base, terminal-twist/arrival-mode). HLA obtains layout origin, reading direction, baseline, orientation and spacing from the user or proposes them explicitly using observed piece extents and table/reachability limits. A word string alone is insufficient. For each relocation segment, its stated morphology/location identifies the target at the first supervised frame; track that physical instance through the interval. RULE P: derive a target footprint from the last supervised frame, using both cameras and audited within-segment views if occluded; fit a rigid correspondence to the entry footprint, preserving holes. Freeze this achieved local pose as the hindsight goal, not as the demonstrator's verified intent or word success. Use endpoint T_base_ee and recorded endpoint twist as a separate optional exit-tool label to explain clearance/transition motion after piece motion has ceased. In particular some cuts end during free travel toward a successor rather than at zero velocity. If the endpoint pose is ambiguous, an offline annotator must resolve it from this retained sequence or mark the corresponding goal/pose loss ineligible; never invent an angle for a symmetric piece. RULE T: tool-position goal is the last supervised T_base_ee and terminal recorded twist; trajectory supervision is original action_json, not differentiated q. These future-derived goals are caller-argument training labels only. Online goals come from HLA planning/current geometry, never a future frame or source index. At each time, instance geometry, obstacle masks, contact candidates, phase and progress update causally from the current paired observations and permitted history. Goal shape is transformed with the same causal registration as the tracked instance but its desired world placement stays fixed until an explicit new call. A pose-symmetry set can be physical for manipulation, but semantic upright orientation is separately enforced; an ambiguous glyph cannot be declared correctly spelled.

## Portfolio rationale (verbatim API output)

Two subtask dataset groups and three independent callable policies are deliberate. tool_position learns noncontact approach/reposition with an explicit waypoint, not letter semantics. piece_relocation learns one physical instance's local planar transformation, including contact acquisition, internal stroke switching, fine adjustment and bounded clearance to an exit waypoint. A per-letter policy, per-word policy or separate model for every corrective stroke would fragment already tiny support and fail unseen identities. Conversely a single word-to-joint trajectory model would entangle inventory, layout, contact and arm redundancy. Translation, off-center rotation and short correction share one geometry-goal problem; a mode-aware representation makes this coherent without cutting away the L-like repeated attempts. Distinct object invocations and revisits are separate sequences. The two piece alternatives have substantive differences: local boundary mechanics with a learned response residual versus dense goal-field correspondence servo that avoids canonical-angle estimation. Both are independently trained on the same 22 invocation examples, not two names for a shared policy checkpoint. A second waypoint policy is not justified by the four supported waypoint examples; use deterministic geometry for predictable variation instead.

## Model inventory (verbatim API output)

Proposed independent learned policies: one compact waypoint residual/mode model (tool_waypoint_v1), one contour-graph contact-response/mode model with constrained short-horizon planning (piece_contact_graph_v1), and one goal-field recurrent visual servo (piece_goal_field_v1). Shared non-policy components: pretrained open-world instance segmentation and open-vocabulary character/orientation recognition, causal multi-object tracking with covariance, robot/tool masking, and a shared scene representation. These pretrained weights are NOT supplied and must be selected, licensed/acquired and evaluated on unseen physical letters; no known-font restriction is acceptable. Train-only mask/track/rigid-transform and phase/contact-proximity labels require annotation/audit; contact remains weakly inferred, not force ground truth. Deterministic components to implement: JSON parser/missingness masks, lens undistortion, camera transforms, workspace/goal conversion, contour/SDF construction, candidate collision checks, reachability checks, word-to-distinct-instance assignment and footprint layout planner, action conversion, joint-velocity follower and safety/status monitors. Assets present: exact NPZ/source RGB/depth references, SHA-256 manifest, per-episode K/distortion and third T_base_cam, wrist T_flange_cam, board calibration, TCP xyz=[0,0,0.2], rpy=[0,0,-90] degrees set as robot ee, and teleop configuration. Assets still needed: actual controller implementation/version and execution semantics; robot kinematic/collision model and limits; verified TCP-to-installed-rod-tip/radius geometry; tabletop/letter-top height calibration and its uncertainty; validated camera/depth scale/registration if depth is used; perception weights and audited labels. COMMON PIPELINE C: parse q,dq,tau_ext,T_base_flange,T_base_ee, action_json and original timing without shifting pairings. Set explicit missing masks for gripper_position=-1, gripper_width_m=NaN, null command dq/target_pose/gripper. Never use these as valid grasp signals. Use calibrated wrist K rather than mixing factory wrist K with its extrinsics; test alternative calibration only as a separately validated asset. T_base_wrist=T_base_flange*T_flange_cam. Undistort original 1280x720 RGB before cropping/warping; retain exact crop/resize mapping. Robot/tool masks come from projected verified geometry plus image checking. Derive letter geometry by ray intersection with verified letter-top planes, accounting for thickness/parallax; until depth scale and RGB registration are verified, raw depth is archived but not a metric feature. Plane uncertainty must propagate into masks/poses/clearances. Existing calibration reports 4.42 px RMS and 3.23 mm pose consistency, not perfect contact localization. Use the same causal estimator at training and deployment; offline smoothed/audited shapes only supervise auxiliary targets and endpoint goal labels. Keep all original frames and metadata; preview resolution is inspection only. Eligibility is per loss: finite valid command fields for action loss, confident track/geometry for normalized-action or response loss, and an actual in-segment successor for dynamics loss. Null dq at initial rows does not invalidate finite v/w supervision. Later implementation must publish retained/ineligible counts per behavior, phase and instance and seek annotation/estimator repair rather than silently dropping difficult L/R/hole interactions. The cut stage neither constructs labels nor implements these converters.

## Generalization design (verbatim API output)

Hypotheses, not established transfer: separate semantic identity from manipulation geometry. An open-vocabulary recognizer supplies character hypotheses and semantic upright orientation, a persistent instance tracker supplies geometry, and HLA matches word positions to distinct physical instances. Manipulation never consumes a character-class embedding or the demonstrated word. For entirely unseen shapes, use measured outer AND inner contours, local boundary normals, tool-radius clearance and current-goal correspondence rather than an alphabet-specific template library or convex hull alone. piece_contact_graph_v1 learns only contact-response residuals and mode selection over deterministic feasible contact candidates; piece_goal_field_v1 learns a causal goal-field servo without needing a unique canonical object angle. New words and layouts are explicit target rigid transforms/goal silhouettes on the measured workspace, with footprint-dependent spacing and collision constraints. New arrangements are expressed by current obstacle masks, relative geometry and HLA staging calls. Evaluate independently: (1) new words/layouts using familiar pieces; (2) entirely held-out physical letter shapes/fonts/concavities, including unseen identities, with single-piece translation/rotation/contact-switch goals; (3) both novel physical letters and novel feasible words together, with new clutter and manipulation orders; (4) repeated-character inventory and impossible/ambiguous requests; (5) perception-only recognition versus manipulation with supplied ground-truth goals to separate failures; (6) calibration, friction, thickness, occlusion and controller stress tests. Use leave-one-episode-out development and leave-shape-family-out tests, keeping every overlapping source interval in one split. Two episodes cannot establish a statistical new-shape claim; additional authorized held-out physical trials and broad perception assets are necessary. Compare the two piece policies under identical goals, source support and perception; ablate geometry normalization, holes, mode memory and future-goal relabeling. Measure pose/silhouette error, neighbor displacement, contact switches, intervention rate, uncertainty calibration and word-level correctness, not just final pixel similarity.

## Calling contract (verbatim API output)

The High-level Agent (HLA), not a recorded spelling sequence, owns request interpretation, inventory feasibility, physical-instance assignment, layout generation, obstacle clearing and policy selection. Proposed calls are tool_waypoint_v1 (tool_position dataset), piece_contact_graph_v1 and piece_goal_field_v1 (piece_relocation dataset). A call contains a persistent scene-instance ID where applicable, a workspace-frame goal, tolerances, protected-instance IDs, speed/clearance limits, timeout and an optional exit-tool waypoint. Return RUNNING, REACHED_LOCAL_GOAL, NEEDS_REPOSITION, BLOCKED, PERCEPTION_UNCERTAIN, CONTROLLER_UNVERIFIED or ABORTED, with geometric error, uncertainty, changed-neighbor list and successor readiness. These are proposed interfaces, not executable policies. Representative evidence-grounded compositions: episode A approaches the wedge-shaped piece, relocates it, shifts the middle barred piece to clear space, moves O-like, stages R-like, moves the middle and upper barred pieces separately, moves D-like, revisits R-like and D-like, repeatedly recontacts L-like, then revisits both barred pieces. Episode B instead moves D-like before O-like and R-like, and moves the upper-left barred piece late. Every stage is another call on current geometry, with temporary clearing/staging poses as legitimate local goals. A caller may interrupt between strokes and change the goal; never change an instance ID silently. If a local goal is reached but the word is not, HLA calls another policy. Final word acceptance requires independent identity, orientation, spacing and distinct-instance checks, never episode-end detection.

## Sharing and diversity audit (verbatim API output)

All policies may share frozen/audited perception, calibration, geometry conversion, safety and controller assets but not trained policy weights or recurrent state. Character recognition and word planning are upstream, not hidden learned labels for manipulation. The same two episodes supply a narrow material/tool/friction regime and largely the same seven-looking-piece inventory; repeated cuts are not alphabet diversity. Contact graph versus goal field is a model/representation/action-generation diversity test, not an evidence expansion. One policy favors confident local boundaries and contact predictions; the other favors reliable dense masks but uncertain canonical orientation or imperfect local mechanics. HLA selection uses these observable confidence measures and geometry, not test success labels. Preserve source hashes, original sample indices, timestamps, missingness, raw commands and original media mappings in every cut. Use exact original paths through source_root and keep goal-label provenance separate. Shared calibration uncertainties and perception failures can correlate alternatives; report that rather than claiming independent safety redundancy.

## Motion coverage (verbatim API output)

Numerical surveys used A[0,9015) with 20 bins and B[0,7730) with 18 bins, then B[3800,4300) with 10 bins. Bins were not semantic cuts. Startup descends from recorded TCP z about 0.365 m; most manipulation is near z 0.047-0.083 m, with lifts/recontacts up to roughly 0.134 m. TCP z is not assumed equal to physical rod-tip height. Planar translation dominates, but nonzero recorded angular commands and changing tool tilt are real supervision: A3900,4319,5219,7400. Do not clamp every w to zero or assume a permanently vertical tool. Object yaw is primarily changed through contact location/direction; wrist yaw and object yaw are distinct. B4120-4200 has large joint reconfiguration (measured dq up to about 0.66 rad/s in the survey) while the tool retracts/reapproaches R-like; it is retained, not classified as corrupt merely for high joint speed, and the joint-limit/singularity monitor must flag it. Translation, yaw adjustment, low/high clearance, free travel, inner-hole/concavity contacts, short corrections, repeated attempts and terminal holding all have action support. Base primary supervision is a contiguous accounting partition: tool startup A[0,600), B[0,380); relocation A[600,9015), B[380,7730). Additional tool supervision reuses A[6120,6251) and B[4000,4251), 382 original rows. Thus proposed supervised uses total 17,127 before per-field eligibility, not 17,127 independent observations. The 26 materialized cuts total 18,087 rows, including 960 context-only uses, while the unique source remains 16,745 records. No N+1 terminal observation is fabricated and no action is inferred after either final record.

## Unobserved cases (verbatim API output)

No demonstrated grasping, stacked/tipped pieces, retrieval off-table, robust jam extraction, intentional multi-object pushing, changes in tool/material/friction, autonomous letter recognition, impossible-inventory rejection or successful manipulation of entirely unseen physical shapes. These are not fabricated as trained policies. Required novel-identity/shape/word functionality is addressed by geometry-only manipulation and open-world semantic/layout components plus independent combined-transfer testing, but is not certified by these two recordings. Broad recognition weights, annotated held-out novel shapes and actual-controller verification are deployment-blocking assets. If recognition cannot disambiguate H/I-like or W/M-like orientation, request clarification once at the semantic level or return PERCEPTION_UNCERTAIN; do not substitute a human choosing every contact. Repeated-character requests require separate detected instances; absent inventory returns INFEASIBLE_REQUEST before motion. Unknown shape holes/thickness require conservative geometry validation, not use of a known-font template. No physical reconstruction from unverified raw depth, timestamp realignment, fabricated terminal observation or silent replacement of missing commands is authorized.

## Overlap rationale (verbatim API output)

Twenty paired rows (about 0.67 s) before and after ordinary object cuts are context-only, long enough for a proposed 12-row causal history but short enough not to merge different-object objectives. End-of-episode cuts have no fabricated suffix. Context before an invocation may show the previous target; its actions are never trained under the new target. Future suffix observations can audit endpoint/handoff labels but cannot enter an earlier policy input. Approach, recontact, final clearance and holds INSIDE each supervised range remain action supervision under the target object and the optional explicit exit-tool goal. This prevents losing transition behavior while avoiding labeling another object's push with the wrong ID. Reuse A6120-6250 for both L-like approach under an object goal and independent tool-waypoint motion; reuse B4000-4250 for R-like contact reset under its persistent goal and an independent tool reposition call. Different conditioning explains the same actions; neither reuse is a new demonstration. For new calls HLA can invoke tool positioning independently or let the piece policy execute its internal approach/reset phase. Within each segment form causal windows of at most 12 paired records, mask absent history, and never concatenate separate cuts. Supervised short unrolls must mask losses outside the declared range. Reset policy hidden state on a new instance/goal, optionally warm it using valid retained/live history and last verified tool command. Deduplicate source identities in perception training and weight shared rows by inverse reuse count when aggregating metrics; each independent policy gets its own normalized training sampler. Balance episodes, instances and contact/approach/reset phases, cap long idle holds at 5% of minibatches while preserving actual zero labels, and normalize long L/R sequences so duration alone does not dominate. Split at original episode and physical-instance lineage before any overlapping cuts or augmentation.
