# egg_interaction_v1 usage

Full executable observation/call/memory/geometry schema is in CALLING.md; policy handoff in HANDOFF.json. Important ABI change: velocity is current **recorded EE-local**, not blade-local. No installed physical API is claimed.

1. Save preinteraction initial third-view RGB and immutable reference ID in Agent session. Arrange independently validated acquisition of the demonstrated spatula with explicit grasp geometry and gripper binding. Stop if missing; policy cannot infer a safe grasp template.
2. Confirm current visual retention and supported egg/pan context. Supply one to five recent paired original720x1280 uint8 RGB/state samples and call task=turn_over_in_same_pan, tool_template=demonstrated_spatula, reset=true, initial_third_rgb, session/reference/setup IDs, verified context flags and six commissioned spread thresholds. State is T_base_ee, tau_ext7, width and image ages/time, not a blade pose or privileged contact label.
3. Active produces six EE rates plus spread and expiry<=.1s. executor_request transforms EE goal to flange via validated T_flange_ee and demands a path/timing-preserving contact segment. Supply live timestamp, commissioned limits, collision/safety geometry IDs and explicit validation flags; unbound execution rejects. Controller must still check live start error, swept collision and force limits. Do not route around the interaction and call it successful tracking.
4. After each segment, reobserve at10Hz and continue with returned finite buffer memory, same goal/reference and only new samples. Gripper is held through a separately validated adapter, never learned from scalar commands.
5. On slip/limit/interruption/infeasibility/staleness/no progress, cancel and clear actor history. Preserve original reference; revalidate before resetting with fresh causal history. Unknown support or off-pan/dropped cases need assistance, not learned recovery. For apparent release, inspect settled face and pan support. Only Agent may declare a verified flip; no recording-ending stop label exists.

Return statuses include active, invalid_observation, stale_observation, uncertain, entry_not_verified, interrupted, unsupported_goal and goal_changed. Any nonactive return has no motion decision and cleared policy memory. Completed_flip is never returned by this actor. Calling fixtures test real recorded inputs with synthetic permissive execution acknowledgements; they certify software behavior only. No deployment/generalization success measured in this package.
