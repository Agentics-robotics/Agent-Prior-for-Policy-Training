# Push v6 — implemented prior and preparation recovery

## Provenance and division of responsibility
The exact original supplied cut/prior is copied verbatim to immutable preparation evidence `original_source_plan.json`, with original metadata in `original_recording_metadata.json`. All twelve buffered cuts and both full executor traces retain their original ranges. Source and implementation versions are retained. This is the authorized fresh Push v6 implementation/final-fit run, not a new cut experiment; Push v5 and Flip artifacts are untouched.

One learned identity-blind geometric interaction selector remains. Supplied planner/controller owns robot travel, descent, withdrawal and guarded bounded contact tracking, not how to push the object. The supplied image-capable High-level Agent owns semantic identity/uprightness hypotheses, feasible injective occurrence-to-instance assignment, explicit spatial layout, staging and ordering. Thus no Qwen dependency or closed-alphabet recognizer is trained/assumed installed. This allocation requires the Agent to reason over actual images, preserve unknown/ambiguity, and request a glyph convention only when genuinely unidentifiable. It is not a claim that semantic novelty was evaluated or that a human chooses each push.

SAM2.1 Hiera-small is a resolved, frozen learned perception dependency (public Meta tensor, Apache-2.0, pinned SHA256 in package.json). Its weights are bundled in the model state but excluded from the optimizer. No other pretrained asset is assumed. Runtime is offline/local.

## Compact sufficient learned problem
The residual is boundary contact, inward heading and short tool distance for one caller-defined SE2 objective. Character, color, word, task order and joint configuration are absent from features. 96 outer/inner boundary points encode centered xy, normals, goal displacement field, loop and curvature. A shared 64-wide point MLP pools mean/max; a shared two-layer 64-wide scorer combines that context with 20 geometric candidate features including clearance, goal alignment, moment arm, metric diameter/tool radius/length and local geometry. It scores 864 candidates (96 contacts x 3 inward headings x 3 distances). Only 18,497 parameters train.

This small categorical joint-choice model is preferable to image/motor diffusion here: robot motion generation is supplied, two source episodes are small, and the output is a finite local interaction choice. No learned dynamics, travel, recognition, termination or success model is hidden. Stateless shape/goal conditioning supports the same decision before approach and at contact. Goal-direction canonicalization removes translation and most planar rotation nuisance; near-zero translation uses base axes, so exact pure-yaw equivariance is not claimed. Physical size remains explicit; no unphysical shape-only scaling or invented success augmentation.

## Numerical supervision and recovery
Original paired indices are authoritative; no timestamp shifting, re-pairing or fabricated terminal state. Raw RGB/arrays remain available. Unverified depth units/registration are not used. q/dq/action_json/tau_ext are not policy targets or force ground truth; gripper missingness is not treated as zero.

A weak common horizontal top-height hypothesis comes from six dominant-height triangulated feature correspondences across three poses, concentrated on textured labels: approximately 75.16 mm base Z, with at least 6 mm uncertainty. This is NOT a validated table plane. Image rectification aids appearance matching only; depths still come from original calibrated camera rays. The first tool endpoint fit gave third-view reprojection discrepancies of about 2.2–24.5 px. It was therefore NOT accepted as an exact absolute contact locator. Final contact localization uses the currently visible narrow neutral shaft endpoint in the original third image, then the nearest supported boundary. The robot tool transform is used for differential short-stroke direction/length, with rotation/height/linearity and available visual-motion agreement checks. Both remain inferred pseudo-labels, not force or tip metrology. Production must supply independently commissioned geometry.

First complete preparation produced 341 rows, but visual review exposed merged neighbors and missing holes. Final perception uses separated automatic foreground interior-point prompts offline, generic workspace grid prompts online, and large enclosed neutral-table patches for hole evidence. It rejects compound/visibility-inconsistent shapes. A subsequent pass retained 311 rows yet zero closed-inner-loop labels: the shaft occluded a thin bridge, turning D-like holes into apparent open concavities. Final repair registers a complete causal hole shape from the cut's first image against the current visible geometry, requiring <5.5 mm residual and >85% bidirectional support within 8 mm. Only causal reference geometry is used; future masks never repair current features. The same optional reference restoration is implemented online. This does not certify all reconstructed contours; residual errors/uncertainty remain reported.

## Examples, loss and final fitting
Every 15 rows plus original sparse anchors is considered: 1075 candidate anchors, not 1075 independent events. Current actor is associated using visible tool proximity plus observed same-shape response, not inferred spelling. Hindsight goal is the same piece's observed rigid pose one second later. Tool prefix ends by 20 mm, 0.2 diameter, or 1 s. Nonlinear/height-changing/rotating prefixes can still provide contact supervision while direction/length are masked. Loss uses TRUE marginal likelihood for unobserved channels, not uniform invented targets. Full labels use soft joint candidate NLL, 7 mm contact and 6 mm length kernels. Unchosen candidates are not physical failure labels.

All 16,745 source rows remain executor/context evidence. Per-anchor reasons explain target exclusions; rejected rows are not declared physically useless. All supported final examples/channels from BOTH episodes enter delivered weights, including development-inspected data: an initial sequential sweep guarantees every row receives gradients, followed by equal total sampler mass per nonempty activity cut. This balances long correlated retries. AdamW, 0.0005 peak LR, warmup/cosine decay, weight decay 0.002, gradient clipping 1, batch <=16, fixed 3000 updates; select final model, no performance search. Both episodes informed conversion, so neither is an untouched independent test. Final fitting errors are not generalization estimates. Actual coverage/readiness is tied to the submitted preparation manifest, not the earlier counts.

## Task generalization and readiness boundary
Required unseen identity, physical shape, word/layout and initial arrangement are separate demands. Agent semantics and explicit layout address new words/identities; identity-free full-shape features, holes, torque context, metric tool access and receding-horizon feedback address the physical transfer hypothesis. Accepting arbitrary labels/goals does NOT prove unseen-shape manipulation. Only two same-inventory initializations exist, with twelve correlated activity cuts and very uneven usable contact coverage. Endpoint success is unannotated.

Independent deployment tests must include: unseen manufactured shapes/fonts/holes/concavities with oracle semantics; unseen identity recognition/uprightness with oracle manipulation; novel words/layouts using familiar inventory; jointly unseen identity/shape/word/clutter without oracles; impossible inventory/repeated characters/ambiguous glyphs; and separate friction/material/thickness/tool shifts. Report object pose error, slip, collateral motion, contact loss and recovery, not just string acceptance. Fully commissioned table/tool/collision geometry, validated guarded executor binding and persistent geometry/semantic association remain deployment prerequisites. No robot execution or new-shape success was measured here. Training readiness is only readiness to fit the supported geometric prototype, not autonomous deployment certification.
