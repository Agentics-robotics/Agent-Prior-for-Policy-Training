# Final actor-quality and calling amendment

This amendment supersedes earlier wording where necessary; package.data_plan references it.

Review of a 311-row preparation showed that causal hole recovery restored six inner-loop labels, but some non-hole actors were still partial silhouettes. A8310/A8370, for example, contain half of a bar-shaped piece cut by tool occlusion. These are not acceptable full-shape goal-conditioned inputs. `quality.filter_prepared` therefore applies a general actor-completeness test to EVERY otherwise retained row, not an approved-index whitelist: current actor must match a same-cut first-frame shape at unchanged metric scale, material-area ratio 0.85–1.18, robust residual <6 mm and >85% support in both directions within 8 mm. Failure means no policy gradient, not discarded raw evidence.

A first completeness pass retained 144 rows and lost all A open-corner evidence, A bar finishing and B loop finishing. This exposed the weakness of using point-prompt subparts as complete initial references. Final reference generation uses SAM whole foreground-component boxes at the original cut start (precontact evidence), while current masks still use separated point proposals. This attempts recovery by improving the reference, not loosening completeness thresholds or whitelisting source indices. References remain measured, causal, same-cut and unscaled. An initial fused or occluded reference can still cause genuine pushes to be withheld; it is not proof the interaction is unlearnable. Tool localization was also corrected to allow a neutral gray shaft over darker brown material, rather than stopping prematurely at the material's upper edge; very bright table openings still fail the shaft intensity test.

The authoritative post-filter reports are `final_quality_audit.json`, `coverage.json` and `quality_summary.json`. `anchor_audit.json` describes the preceding target-conversion stage. Previous source/preparation snapshots are preserved. All final retained rows/channels, including development-inspected evidence, enter gradients; none is reserved as an independent test. All 16,745 original rows remain context. Low/zero surviving cuts must be assessed against shared behaviors elsewhere, not silently claimed fully supervised. Residual mask/contact uncertainty and incomplete obstacle context remain, so inferred supervision is not ground truth.

## Mandatory online flag
For an already associated Scene, add `geometry_complete_validated: true` to the CALLING.md example. It asserts the Agent's perception/scene-validation stage actually checked actor completeness, persistent association and conservative obstacle coverage using causal views/references. Merely obtaining SAM masks does NOT justify this flag; partial geometry needs another planner-generated view or a blocked result. Missing/false flag yields `needs_view`. Optional causal_shape_references are further checked by executable shape registration in act. No image classifier substitutes for actual geometry validation. This exposes a remaining autonomous perception-integration prerequisite instead of pretending Scene truth exists in the demonstrations.

Calling checks explicitly refuse an unvalidated Scene. Real-contour tests set completeness and commissioning synthetically and do not establish a deployed validator's accuracy. Raw RGB tests return association-needed proposals, never permission to push. Full robot/tool collision models and commissioned guards remain separately required.

## Readiness scope
Submission readiness is assessed against the exact final preparation manifest. Enough supported weak geometric supervision to fit a small prototype is distinct from certification of semantic/layout/perception/executor autonomy or unseen-shape success. Only prototype-fitting readiness can be established here. Final fitting diagnostics are in-sample pseudo-label agreement. Neither 3000 updates nor interface checks imply robot success.
