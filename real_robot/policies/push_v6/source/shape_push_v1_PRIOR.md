# shape_push_v1 prior

See PRIOR.md for the complete implemented prior, source retention and evidence-based changes. One shared 96-point encoder and joint contact/direction/length scorer operates on measured geometry, goals and clearance. The frozen SAM2 tensor is explicitly pinned in package.json. Small masked categorical imitation is selected over diffusion because travel/control is supplied and only two independent episode initializations exist. All valid retained rows from both recordings enter the final gradients, balanced by activity cut; final diagnostics are not independent evaluation. No object identity, word, joint command or success target is learned. Tool/plane estimates remain inferred and uncertain; production commissioning is mandatory. Required unseen shapes/identities/words/layouts must be independently tested as specified in PRIOR.md.
