# Calling contract

`act(model, observation, call, memory, spec)` performs metric support sampling, goal canonicalization, state/history encoding and learned inference. It never reads source recordings or future frames. `predict` returns3 mixture weights and3 two-component normalized means flattened to9 numbers for reload diagnostics, not a robot action stream. `executor_request` creates a geometric objective only; there is no hardware IO.

## Agent pipeline
1. Receive word plus layout baseline origin/direction, upright direction, region, spacing and tolerances. If omitted, propose an explicit layout for user acceptance. Interpret semantic identity/uprightness from RGB using the supplied visual Agent. Resolve each character occurrence injectively to a persistent physical instance. Unknown identity or impossible counts return ambiguous/impossible_request, not success. No learned recorded-alphabet recognizer or assumed Qwen is hidden here.
2. Obtain a causal scene using commissioned calibrated sensing. `inventory` offers frozen automatic SAM2 class-agnostic proposals from RGB/camera/top-plane, with observed support points and contours in base-parallel P; it explicitly returns incomplete/unvalidated geometry, scene-scoped IDs and unknown semantics. Agent/sensing must associate persistent instances, resolve merges/splits/occlusions by additional views, and validate complete contours before initial contact. No human selects each move. Geometry/identity validation is an upstream deployment dependency, not certified by this training package. Do not set validation flags merely because SAM confidence is high.
3. Assign per-instance SE(2) target transforms, pack measured shapes without overlap, choose unblocked targets or staging locations from occupancy. For distant goals choose a local feasible pose with <=80mm maximum support displacement. A goal transform acts on **current P points**: `goal_point = R @ current_point + t`; t is not simply centroid displacement when rotation is nonzero. The selected track/reference gauge must be consistent with the Agent's target pose. Semantics never enter the network.
4. Call `shape_push_v1` with `contact_confirmed=false` before travel. This invokes deterministic accessible contact initialization, requiring validated complete shape/hole geometry, all protected contours, workspace and tool radius. It returns proposed_prepare, not a learned contact estimate. Executor checks full tool-envelope insertion, table clearance and allowed-contact patch, prepares at standoff and reobserves.
5. At confirmed fresh contact, call with `contact_confirmed=true`. Confirmation must come from commissioned sensing/guard logic, not recording height, a SAM mask or a guessed force. The network returns a planar **EE translation** in P, at most15mm and1s. EE orientation and current height are held; it does not report a physical boundary point. `executor_request` transforms delta by T_base_P and adds it to the live EE position. The supplied planner/controller must validate and track the local stroke with intended-contact allowance and guards. Learnably predicted motion is never automatically safe.
6. Observe after each stroke; recompute pose and protected-object motion. On residual error repeat, reinitialize another contact, change staging target or move to a different instance. Contact loss, collision, stale state, guard stop, interruption or neighbor motion cancel continuation. Two distinct nonprogressing tickets trigger replanning. Final whole-word geometry and semantic correctness require independent stable observation; at_goal_observation_not_task_success is only a local observation status.

## Observation
All distances meters, angles radians, matrices explicitly source-to-destination. Required: `scene_revision`, `time_s`, `calibration_id`, `instances`, `T_base_ee[4,4]`, `T_base_P[4,4]`, `uncertainty_m`, `chart_validated`. Each instance: unique string `instance_id`, `support_points_P[N,2]` currently visible occupied surface points (not full boundary, >=5), optional complete `contours=[{xy:[[x,y],...],hole:bool}]`, `geometry_complete`. Do not synthesize support from unseen parts of an offline shape template. P is a locally horizontal orthonormal piece-top chart; online EE height is relative to this chart. Current EE axis plus current support/goal are sufficient for learned continuation. The training surface chart has an8mm absolute uncertainty and no certified table/tool clearance.

Optional causal `previous_delta_P_m[2]` from approximately0.2s earlier with `history_dt_s` in[.15,.25]; otherwise masked. Never pass planned/future displacement as history. For initialization additionally `workspace` polygon, `tool_radius_m`, global `geometry_validated` and complete protected-object contours. Full tool geometry remains in the executor, not approximated by this radius for final collision checks.

## Call and memory
Required call: `instance_id`, `goal_R[2,2]`, `goal_t[2]`, matching `scene_revision`, `now_s`. Options: `contact_confirmed` (default false), `max_stroke_m<=.015`, `position_tolerance_m`, `previous_outcome`, `previous_ticket`, `interrupted`. Scene age<=.25s. This is a proposal interface; executor latency must use stricter commissioned bounds if necessary. Reset external memory at a new instance/reference gauge, changed goal/calibration, re-association or interruption. Memory tracks objective identity and failures only; no network hidden state or recording-phase memory survives. Distinct ticket IDs are required for retry accounting.

Example: observations supply a persistent new-shape track and current points; Agent transforms its requested slot into R,t. `act(..., {'instance_id':'part7','goal_R':[[1,0],[0,1]],'goal_t':[.01,0],'scene_revision':42,'now_s':t,'contact_confirmed':False}, None, spec)` requests first contact. Execute only after commissioned planner validation, then refresh scene and call with confirmed contact. Never reuse the stale prepare scene for a learned stroke.

## Executor binding
Contract fields: `commissioned`, matching scene/calibration IDs, `T_base_P`, `guard_profile_id`, `tool_geometry_id`, `max_speed_m_s`. Initial prepare additionally requires `R_P_tool`, calibrated `support_point_tool_m`, `contact_height_P_m`. Planner receives tool contact/standoff poses for prepare or start/end T_base_ee for continuation, requires full tool/robot envelope and table-clearance validation, permits selected-actor contact only and protects all others. Speed is capped at15mm/s and duration1s; the low-level controller must terminate at either endpoint or time budget. Profiles must commission speed/acceleration/torque/contact-loss/latency guards and interruption behavior. `requires_planner_validation` is not acceptance or execution. Missing calibration returns blocked_uncommissioned; no speculative robot command is issued.

## Executable scope
`calling_cases` covers synthetic continuation and deterministic initialization, missing observation, stale revision, interruption/reset, unvalidated chart, local goal observation and guard feedback; it also includes a real retained-source support/EE fixture with its hindsight numeric goal explicitly on the call side. Synthetic commissioned flags are interface fixtures, not robot commissioning. The real-source executor contract is intentionally uncommissioned. Reload tests establish callable tensor/decision/executor formatting, not RGB-to-autonomous-track quality, physical safety, planning acceptance or task success. `inventory` is not exercised by these calling fixtures. Required novel-shape/word/semantic and physical tests are listed in PRIOR.md.
