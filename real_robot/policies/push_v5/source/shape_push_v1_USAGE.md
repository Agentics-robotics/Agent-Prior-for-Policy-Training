# shape_push_v1 usage

Use the executable contract in CALLING.md. At first contact pass a fresh selected instance, explicit current-to-goal SE2 transform in P, complete validated contours/tool/workspace and `contact_confirmed=false`: deterministic initialization proposes a contact. After planner preparation and fresh commissioned contact confirmation, pass current visible occupied support points, T_base_ee, T_base_P, uncertainty and optional causal0.2s displacement with `contact_confirmed=true`: the learned model proposes <=15mm planar EE continuation. Do not feed an observed future pose/image online; the numeric goal is supplied by Agent layout/staging.

All points/lengths are meters, P chart coordinates; rotations radians in SE2 or proper matrices. Network memory is stateless; reset external objective/failure memory on instance/goal/calibration/reference changes and interruptions. `executor_request` returns a pose/path objective requiring full planner/controller validation; it does not execute. Missing calibration blocks physical execution but does not invalidate direct offline EE-delta labels. Preserve current height/orientation only within commissioned contact conditions. Feedback stops on guards/loss of contact/neighbor motion and replans after two failed tickets. Local at-goal status is never whole-task success.

Example call fields: `{instance_id:'part7', goal_R:[[1,0],[0,1]], goal_t:[0.01,0], scene_revision:42, now_s:10.0, contact_confirmed:true, max_stroke_m:0.01}`. Required observations and synthetic/source-fixture check scope are fully specified in CALLING.md. Invoking with unseen identity/word is syntactically permitted but does not constitute measured new-shape competence.
