# Revised prior: visible-motion-conditioned continuation

## Preserved starting point and failure
The original cut_v6/source_plan (copied verbatim by preparation), ORIGINAL_CUT_PRIOR.md, annotations.json, geometry.py, recovery.py and preparation.py remain. Journaled earlier policy/package versions and their failed checks are not overwritten as history. PREVIOUS_ASSESSMENT.md preserves the completed blocked assessment. It rejected 142 provisional contact rows for sound reasons: fragment boundaries were mislabeled as actor exterior, holes were occluded, and calibrated visible-tip position was not a verified support surface. This revision does not certify those labels or silently loosen their gates.

## Evidence-based change
The residual learned task is now a **short planar EE continuation at a currently established contact**, not a physical-boundary contact classifier. Its label is an exact difference of two recorded T_base_ee translations; pose stability, straightness and displacement limits define compatibility. A caller-equivalent local achieved SE(2) goal comes from forward/backward RGB corner tracking and robust rigid fitting. No whole-mask registration is used. A component is a visible occupied support patch, not a full physical instance, hole, boundary normal, force measurement or verified contact. Fragmentation can reduce context, but no longer invents physical contact truth. The current support cloud is sampled before future inlier fitting and is unchanged by future selection. Future pixels enter only goal/eligibility/actor annotation, never causal tensors.

This adaptation gives up learned initial-contact selection. It is replaced explicitly by a deterministic geometry/accessibility prior: sample complete validated outer/inner contours, prefer an accessible inward contact aligned with the desired rigid displacement field there, and let the supplied planner validate the full tool/robot envelope. This is a heuristic, not a learned dynamics model or guaranteed successful contact. Agent retries use observations, not a recorded script. Any role needing unverified full geometry requests a new view rather than using a fragment as a whole object.

## Compact representation and model
64 currently visible occupied points, goal-displacement vectors at those points; measured current EE offset, height relative to surface chart, shaft axis, last0.2s displacement with missingness, visible extent and uncertainty. Center on observed support and align x to its requested centroid displacement. No letter, font, color, word, joint configuration, episode/index or future image enters the network. Metric scales are retained (positions/.1m, goal vectors/.05m, delta/.02m). Inputs can be partial surface support: they are not signed-distance boundaries. Mean/max pooled32-unit point encoder and64/48-unit head predict a3-mode2D displacement mixture. Highest-weight mode is executed only as a bounded geometric objective with fresh contact/guard validation. This small mixture handles action ambiguity without a high-dimensional diffusion model trained on two episodes.

Loss is heavy-tailed mixture NLL with fixed3mm action scale. This is not uncertainty in the recorded robot translation; it regularizes multimodal behavioral choices. Mild input perturbations and history dropout address visual/temporal uncertainty. A-train/B-development with original interaction-group-balanced sampling, AdamW, cosine decay, maximum800 updates; select checkpoint by macro-group B measured EE endpoint error, with patience after400 updates. B was inspected during design and is not an untouched test. Zero/goal-translation baselines are logged. No model is selected on physical success.

## Calibration and uncertainty
The chart is the prior inferred horizontal piece-top hypothesis z=.068m, not verified table height. Reproject both flow endpoints at z=.060 and .076; common static height error affects differential motion far less than independent8mm endpoint noise. The gate uses max(1.5mm, rigid RMS, split-fit disagreement, height sensitivity). Absolute support input uncertainty remains8mm. Measured EE deltas bypass the inferred tool-cap conversion entirely. An exact tip radius/support surface/table clearance is unnecessary for this offline loss, but indispensable for physically safe initialization/execution. No raw depth units or gripper values are invented. Image pairing follows original indices; age gates do not resynchronize clocks. Relative image/state timing bias remains an uncertainty and data limitation.

## Required transfer and evidence limits
Identity/words: the supplied visual Agent resolves semantic hypotheses and assigns distinct physical instances, including repeated characters; it must return ambiguity/impossible-inventory rather than guess. Explicit baseline/upright direction/spacing/region define per-instance pose goals. Geometry: the learned input has no shape vocabulary and accepts new occupied point sets; initial contact uses measured contour geometry, not stored letter templates. Replanning/staging/order are Agent decisions driven by occupancy and measured progress. These are mechanisms for transfer, not measurements of transfer.

Required commissioning/evaluation includes held-out manufactured shapes/fonts/holes/concavities with oracle semantics; independently novel identities/counts/upright orientations; novel words/layouts on familiar pieces; jointly novel identities/shapes/words/clutter without oracles; infeasible/ambiguous requests; material/friction/tool changes; initial-contact and continuation performance separately. The two same-inventory episodes do not establish any of these. No new-shape success, robot success rate or autonomous perception success is claimed. Flip egg has no supplied data here.
