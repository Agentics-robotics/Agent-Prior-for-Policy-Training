# cut_v5 candidate-policy library

This is an implementation submission for **three independently trained priors**, not a robot execution system or a claim of successful generalization. The outer runner, not this source, performs the prescribed 20,000 AdamW updates per policy, seed 0, EMA 0.999, 500-step warmup/cosine schedule and 2,000-step checkpoints. There is no preliminary performance study, held-out evaluation or optimizer in this package.

Start with [POLICY_CATALOG.md](POLICY_CATALOG.md), [CALLING.md](CALLING.md), and [HANDOFF.json](HANDOFF.json). Each policy has its own prior and usage document. Files are API-authored in English; no pretrained assets were acquired.

## Responsibilities and model choices

* `tool_waypoint_v1`: noncontact TCP waypoint motion, including startup and between-stroke reposition. A geometric route anchor plus recurrent, mode-gated bounded command residual. Four invocations are too little evidence to fit a broad diffusion trajectory distribution.
* `piece_contact_graph_v1`: one selected instance's planar relocation. A 32-node outer/inner-contour graph, contact scores, constrained positive-normal/tangential proposals and a weak learned response model. Receding **one-step proxy** planning replaces high-dimensional action diffusion. It is not a calibrated friction model.
* `piece_goal_field_v1`: independently weighted dense SDF/correspondence recurrent servo. It can express a silhouette objective without assigning a canonical glyph angle. Reset/exit/hold modes preserve nonmonotonic strokes. Diffusion was considered but not selected given two episodes, unreliable contact labels and the value of frequent causal correction.

The executor's one-step reload check did not constrain these choices. All three have approximately two million parameters, 32-example minibatches and modest memory use on a 24-GiB GPU. All trainable encoders, heads and recurrent cells live in each independently constructed `Prior`; **no policy weights or memory are shared**. The field policy is not an alias for the graph checkpoint. Shared code is deterministic perception, geometry, cache construction and interface logic.

## Evidence and immutable data accounting

All 26 original cuts and their supervised ranges remain unchanged. There are 16,745 unique paired source rows, 18,087 materialized context/target uses, and at most 17,127 supervised anchor uses before invalid-command exclusions. The 382 reused rows belong to distinct tool and piece invocations, not additional independent demonstrations. Both piece policies use the same 22 piece invocations; the tool policy uses its four assigned invocations only.

`prepare_data` visits original RGB once per source row, tracks causally, then builds cached, segment-specific goals/features. `native_action` is exact concatenated **float64 recorded v,w**, unshifted. Measured state dq never substitutes for command dq or v,w. Valid zero commands and nonzero angular commands are retained. Missing command dq is encoded separately and does not invalidate action supervision. No terminal successor is fabricated; motion targets require a real, eligible next row inside the same supervised range. Context-only rows are never action targets. Four snapshots at offsets 11,7,3,0 span at most twelve records; histories are bounded by that segment's context start. The persistent scene tracker is separate from this bounded policy history, and may carry identity from earlier causal views of the same episode.

The cache includes source episode/index/segment ordinals, history indices/masks, command dq and validity, phase/contact/motion eligibility, goal validity and inverse-reuse metadata. Raw commands/media/transforms remain in the original source and manifest; the cache is not a replacement archive. Numeric arrays only, no object arrays; a byte-budget check enforces 64 GB. `public.progress` publishes **each segment's** retained/excluded action counts, mode counts, confident geometry/motion counts, endpoint confidence/fit and policy eligibility. These are determined by full preprocessing after submission; this document does not invent counts. Entire missing-goal segments are explicitly reported, not hidden.

Sampling balances episodes and invocations, then present weak phases. Holds receive 5% per invocation when nonhold examples exist; zero labels are not removed. Long L/R sequences therefore do not dominate merely by duration. Use `reuse_count` to downweight duplicate source uses in pooled reporting. All authorized demonstrations are training data this round: no overlapping-source split or validation score is represented as independent evidence.

## Executable perception and geometry adaptation

No segmentation/recognition weights, audited masks, verified physical plane or rod model were supplied. Instead, `geometry.py` implements:

1. Original-resolution RGB inverse-distortion/plane remapping using recorded K/distortion. This is a single-resampling equivalent of undistort then plane warp, retaining explicit original pixel mappings. Wrist uses **calibrated** K and `T_base_flange @ T_flange_cam`, not factory K or TCP as flange.
2. A shape-independent HSV brown foreground estimator suited to the inspected pieces against a light table. Stable third-view support is repaired locally with wrist foreground within three map pixels; unregistered union is not treated as ground truth. Dual-view disagreement remains diagnostic. A 3x3 close may remove very small holes; larger inner boundaries are explicitly retained. Robot/rod grayscale appearance is rejected photometrically, **not** by a fictitious verified geometric tool mask.
3. Initial offline visual seeds at episode zero for seven morphology-based persistent handles, grounded in the inspected images. Seeds associate an instance with the frozen segment description. They are not semantic labels or neural inputs. Runtime uses a fresh caller-selected scene seed instead, not source IDs or endpoint indices.
4. Bounded local rigid-template tracking with visible-support confidence, slow occlusion decay and no identity reassignment on loss. Identity under prolonged occlusion, merged masks or touching pieces is **not certified**. Discrete raster rotation and template occlusion can drift. Confidence is a heuristic, not a calibrated probability.
5. Outer and hole contour extraction, signed distances, small-grid rigid mask registration with symmetry ambiguity, metric-scale graph features, dense correspondence fields, waypoint/orientation error, neighbor monitoring and limited geometric screening.

The default W origin and orientation are built from the recorded board transform, flipping its normal toward base +z while keeping board x and constructing y=z cross x. **The board plane is only a proxy for the letter-top plane.** A 30-mm conservative design margin is used; it is not a measured standard deviation. The retained calibration reports 4.42-pixel reprojection RMS and 3.23-mm consistency; these do not certify contact localization. A caller can supply an independently measured `T_base_W` whose z=0 is the relevant piece-top plane, uncertainty and verification status. Per-view depth scale and registration are unverified: raw depth is not used as metric evidence. TCP is not asserted to be the physical rod tip.

The scene raster covers W x=[-0.2,0.8), y=[-0.35,0.65), 256x256, 3.90625 mm per cell. The model gets a target-centered 64-square patch at native metric resolution (0.25 m extent) containing selected SDF, desired SDF, other occupancy, TCP heatmap and two correspondence components, plus coarse whole-scene occupancy and goal-validity channels. Tool crops center on TCP. Remote goals remain represented by displacement/flow and state. Graph features use the full-resolution contour. No arbitrary image rotation, synthetic shape warping, inferred w-frame transformation or unverified reachability augmentation is applied.

## Privileged labels, losses and missingness

Endpoint TCP/terminal v,w are **training-only goal labels** at the last supervised row. A piece goal is the causal track's endpoint footprint, accepted only above fixed visibility and rigid-fit thresholds. It is an achieved proxy, not verified demonstrator intent, word success or audited pose. Symmetric goals need not receive an invented canonical angle. Motion auxiliary labels use only actual in-segment successor track displacement and incremental angle, masked for confidence/large jumps. Phase labels use recorded zero/nonzero twist, vertical numeric intent, proximity and endpoint-tool/contour error; they are weak categories, not contact truth.

When the endpoint piece mask or current track is uncertain, finite native command supervision **is retained**, with missing geometry/goal flags and the endpoint tool goal; confident object-goal/motion losses are separately ineligible. This is a deliberate degradation rather than silently discarding difficult L/R/recess/recontact actions. It may teach transition imitation without the intended piece goal on those rows. Coverage reports the degradation per segment; repairs require authorized annotation, not invented goals. Endpoint masks/motion never become future observation inputs online.

Training uses normalized interaction-frame linear commands and untouched numerical serialized w channels. The linear basis follows the proposed contact normal/tangent and full W-to-base rotation. This is a reversible numerical representation under the recorded base-translation declaration, not a verified physical decoder. Huber cloning, small heteroscedastic NLL, mode cross entropy and residual regularization train the policy. The graph additionally trains nearest-boundary weak selection and confidence-masked response likelihood/Huber terms. The field trains masked motion auxiliary terms, without imposing monotonic goal reduction. The tool has a command-residual auxiliary. All loss terms act on network outputs; analytic geometry alone is not presented as learned improvement.

## Agent, semantics and safety boundary

The HLA owns instance assignment, local spatial objectives, staging, protected identities and policy selection. `inventory` returns current geometric candidate handles, not recognized letters. `plan_layout` implements distinct-instance assignment and footprint-dependent spacing **from caller-provided current semantic probabilities**, and returns an inspectable proposal. It does not contain an unavailable open-vocabulary model. Without semantics it returns uncertainty; count impossibility is distinguished from semantic ambiguity. Supplying semantic hypotheses is an explicit autonomy dependency, not a human choosing individual pushes. No known-font template is used by manipulation.

`act` accepts physical objectives and returns usable learned **candidate** v,w plus errors, weak uncertainty, phase, changed neighbors, stale/identity checks, budgets and readiness. Fresh verified intent matrices can enforce a physical translational speed cap and a short planar TCP/obstacle screen. They do not establish full rod/arm swept-volume clearance. Joint margins/torque thresholds are checked only when supplied; singularity/reachability is explicitly unchecked without the missing robot model. Clearance requests remain unverified; the path uses a proxy 0.10-m W TCP lift floor. Default candidate status is `CONTROLLER_UNVERIFIED`, not a fabricated RUNNING robot. Physical successor readiness is always false in this package.

`decode_action` is deliberately disabled even if a caller asserts verification. No recording-controller implementation or follower has been retrieved; no seven-joint commands are invented. A future adapter must establish native units, serialized w frame/origin, TCP/rod offsets, holding/filter/watchdog semantics and the 20-Hz command/30-Hz paired-record relationship, then validate constrained follower reconstruction against nonnull **command** dq and physical responses. That requirement does not prevent offline learned candidates now.

## Required generalization and remaining evidence

Geometry-only manipulation accepts new physical contours, holes and explicit layouts rather than letter/word embeddings. This is the implemented mechanism addressing unseen shapes, not evidence of success. The color estimator, two-episode mechanics support, calibration proxy and missing recognition limit autonomous new-letter operation; a fresh shape-independent external union mask can be supplied through the same raster pipeline. Such masks and semantic labels must be actual causal live inputs, not asserted assets.

Independent authorized tests must separate: familiar pieces/new layouts and words; entirely held-out physical shapes/fonts/concavities; combined novel shapes and words; repeated-character inventories/impossible requests; perception versus manipulation with supplied geometry; controller/calibration/friction/occlusion stress. Keep original episode and physical-instance lineage together when evaluating overlapping cuts. Compare the alternatives under identical goals and perception; neither is ranked here. No autonomous jam escape, grasping, stacking, semantic success, calibrated force, physical safety, or new-shape generalization has been established by these recordings.
